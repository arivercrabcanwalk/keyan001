## 1. 场景与共享可行性层（所有方法完全相同）
- 合成天气（WX-E），H=480 min 班次；**作业窗口 T_END = H + 240 min（8 h 班次 + 4 h 加班 = 12 h 作业日）**。依据：电力行业疲劳管理
  标准一般要求"班次+加班不超过 12 h/24 h"（抢修可至 16 h），见 SURVEY_v5_ZH.md §4。窗口内必须 100% 完成。
- v4 层（拆分、最晚出发、移交、URG_FORCE、收工后风场衰减）+ **v5 新增**：
  (a) **备用机兜底**：移交时若无在半径内且有余量的接收机，激活站点备用机（成本 C_BACKUP=200 ≈ 2 次失败）；
  (b) **时间再平衡**：某机剩余计划在窗口内做不完时，尾部目标逐个转给半径内时间/值勤余量最大的无人机，否则转备用机。
- 试点验证（v1，26,600 次运行，6 种方法，B 全量 50×20、L、D、C、A、P4a/b、P3）：**所有方法 100% 完成，0 个排除单元**；
  物理不可达的紧急请求（任何站点半径外或无风往返能量超容量）占 0.45–2.03%，对所有方法同样排除（沿用 PREREG_v4 §2）。
- 排除规则（不变）：仅当某单元在物理上不可完成（A1 与 N1 均失败且诊断为物理不可达）才对所有方法排除；报告排除数（目标 0）。

## 2. 指标
- **门槛（第一）**：complete = 窗口内计划目标 100% + 所有物理可达紧急请求被服务；每方法报告 complete 比例。
- **主指标 J5** = cost(固定 + 0.5·忙碌分钟 + 备用机成本) + C_OT·加班 + 30·高优先级迟到分钟 + 10·普通迟到分钟 + 100·失败次数，
  C_OT = 1.0 /（站·分钟），加班 = Σ_站 max(0, 该站最后一次作业结束 − H)。**J5 不含 makespan 项**（理由：makespan 不是运营目标，
  运营约束是作业窗口与加班成本；见 DESIGN_v5 §2）。
- **约束（相对）**：在同一批天上 E[加班_RL − 加班_N6best] ≤ 0（RL 的加班不多于冻结的调优规则 N6_best）。RL 不能靠拖延取胜。
  （试点 p5c 曾用绝对预算 200 站·分/天：训练分布上满足（val 162）但 dev 上 237 超标 → 绝对预算不随天/图分布迁移，改为相对约束；见 PILOT_v5。）
- 次要：cost、fails、ontime_h、CVaR90(迟到, 高优先级)；描述：n_backup、ms_p99。
- **附录（如实、不省略）**：makespan、末次作业结束、v4 口径 J_v4（含 0.5·mk）。

## 4. 学习方法（RL5）
- 策略网络：pomo_v2 初始化（同 v4），特征 NG 40→48（窗口余量、加班阶段、+30/+60 min 预报风速及趋势、本机/全队剩余工作、值勤余量）。
- 学习器：OpenAI-ES（对偶采样、CRN、中心秩、Adam），**约束 ES**：F = J5 + λ_V·(未完成+漏紧急) + λ_OT·加班，
  λ_V ≥ 1000（违规时对偶上升），λ_OT 对偶上升（步长 0.002/站·分超额，投影到 ≥ 0），预算 200。
- §4.1 约束更新（由试点 p5r 冻结）：λ_OT ← max(0, λ_OT + 0.005·e)，每次迭代一次；参照规则 = 阶段 1 冻结的 N6_best；
  选择时用固定罚 5/站·分（val 上超出参照的加班）。
- 超参（由试点冻结）：pop 16 对偶对、batch 16 天、σ 0.02、lr 0.01、**250 次迭代（固定，等算力；未达迭代数的运行不得被选用）**，
  val 64 天每 10 次迭代。种子 0、1、2。
- 变体（均 3 种子、同算力）：main；nf = 屏蔽天气预报/临近预报特征（20 维）；ne = 屏蔽紧急任务特征（28 维）；uc = 无加班约束（仅 C_OT 计价）。

## 5. 选择规则
每个（变体, 种子）运行：候选 = {val 最优, 最终}；各在 dev（20 图 × 6000–6019）评估一次；
选 dev J5 最小者，约束 complete=100% 且 dev 加班 ≤ N6_best 的 dev 加班（uc 无此约束）；否则标记 feasible=False。

## 6. 检验（顺序固定）
① 门槛表（所有方法、所有测试集）。② **H1**：RL5（种子均值）对每个可实现基线 {A1, A2, N1_240, N6_best, R_N6best, Rfc_N6best, POMO_mean} 的 J5，
Holm(7)。③ **H2**：RL5 加班对 N6_best 非劣：相对差的交叉 bootstrap 95% 上界 < +5%。④ 次要：cost、fails、ontime_h、cvar_h 对所有基线，Holm(28)。
⑤ 消融 Holm(5)：RL5 vs nf、ne、uc、POMO（无 ES）、A1（无 RL）。⑥ 权重敏感性：C_OT∈{0,0.5,2,4}、失败×0.5/×2、高优先迟到×0.5/×2、备用机×0.5/×2。
⑦ 附录：mk、J_v4（Holm，描述）。窗口敏感性：WX_OT=180/300（Test-A 20 天子集，RL 不重训）。
统计单元：地图级（天平均）Wilcoxon + Holm；天聚类 Wilcoxon（天气按天共享）；地图×天交叉 bootstrap；rank-biserial r。
"确认" = p_Holm<.05 且 p_day<.05 且交叉 CI 不含 0。主测试集 = Test-A；B/C/L/P4a/P4b 为泛化（同一检验，单独报告）；P3 探索性。
