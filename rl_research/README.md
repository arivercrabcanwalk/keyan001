# LRPHSD 的强化学习扩展研究（rl_research）

本目录是在 Liu et al.（EJOR 2026）LRPHSD（SABS/DABS 换电站、异构无人机、多航次）及其 TSALNS 算法基础上做的 RL 扩展研究，包括代码和研究记录。仓库根目录下作者的原始文件（README.txt、code/、data/、results/）没有改动。

完整发现、数字和统计检验见 **[PAPER_FINDINGS.md](PAPER_FINDINGS.md)**（A–F 节）。各子项目的进度和复现命令见各自的 `RESUME.md`。本文所有数字都摘自这两类文件。

## 目录
| 目录 | 内容 |
|---|---|
| `rl_v3/` | 基础框架：Python/numba 版 ALNS 引擎（`engine/`）、10% 电量余量、目标与约束改造、闸门实验（A、B 节） |
| `rl_rt/` | 构造式 RL（注意力模型 + POMO/BC，numba 解码），用于毫秒级重规划（C 节） |
| `rl_wind/` | 风场扩展：风速风向、OU 扰动与阵风、强风、锋面过境，以及按航次修正、自适应余量、航次排序三类 RL 设计（D 节）。`engine/` 是加入风模型后的引擎 |
| `rl_dyn/` | 在线紧急任务：仿真器、REINFORCE/PPO-POMO/PPO-GAE/A2C/API，作者方法三种在线化版本 A1/A2/A3，以及 E8 合表（E 节） |
| `rl_ppo/` | PPO/A2C 动态算法配置（DAC），分段控制 ALNS 的温度、修复候选数、破坏强度和是否重启（F 节） |

## 运行环境
- 仅用 CPU。Python 3 + PyTorch 2.9（cpu）+ numpy 2.5 + numba/llvmlite。
- 依赖安装：`pip install torch numpy numba scipy`。原环境把 numba 装在 `rl_rt/pylib`，用 `PYTHONPATH` 引入。venv 和 pylib 没有上传。
- 各子目录的 `RESUME.md` 写了具体的训练、评估命令；`*.sh` 是批量实验脚本。
- 模型权重（`*.pt`）和大体量原始结果（`*.jsonl`、日志）没有上传，需要用脚本重新生成。

## 各条线结论摘要
- **A/B 框架：** 原 TSALNS 在能耗扰动下很脆弱（约 51% 失败）。留 10% 电量余量可以做到零失败，成本代价小。同样留余量时，我们的成本更低，HV 和 makespan 更好，短预算下也有优势。另外发现了 Liu 原代码里的"幽灵大机"缺陷。消融表明，这部分优势来自框架和搜索引擎，不来自 RL。
- **C 构造式 RL（no-go）：** RL 贪心解比参考解差 13.7% / 10.3%，而 10 ms 的 ALNS 只差 3.75%。结论是不可行，如实写作负结果。
- **D 风场：** 对作者原版 TSALNS（不考虑风）：J 低 19%–63%，失败减少 85%–99%（p≈1e-16）。对接入风速预报、调好余量的 TSALNS：J 低 1.1%–2.2%。三种 RL 设计都没有显著胜过调好的 NoRL。一个非 RL 发现：按机型分开留余量（例如小机 0.4、大机 0.2）比统一比例好 0.4%–1.2%。
- **E 紧急任务（RL 主要胜出点）：** E8 合表，Liu-50 × 30 天，配对 Wilcoxon + Holm 校正：

| 组 | 方法 | J | 准时率 | 高优先准时率 | 响应(分钟) | 单次决策耗时 |
|---|---|---|---|---|---|---|
| 作者 | A1 TSALNS + 最近空闲机派单 | 927.3 | 84.6% | 76.3% | 8.96 | 0.01 ms |
| 作者 | A2 插入式在线化 | 1020.9 | 56.6% | 49.8% | 30.7 | 0.02 ms |
| 作者 | A3 滚动重优化（1 s） | 1001.1 | 61.0% | 53.2% | 24.5 | 604 ms |
| NoRL | myopic | 910.5 | 85.9% | 77.6% | 8.59 | 0.01 ms |
| NoRL | static30 | 887.8 | 92.5% | 88.1% | 6.14 | 0.004 ms |
| RL | 我们的 RL（3 个种子） | **882.0** | **93.6%** | **90.3%** | **5.42** | 0.06 ms |

  RL 对 A1：J −4.9%；对 A3：J −11.9%，50 个算例全胜；对 static30：J −0.65%（p=4.5e-5），高优先准时率 +2.3 个百分点，响应 −11.8%；对 rollout M=8：J −1.1%，显著；对 rollout M=32：J 打平，但决策快约 4000 倍。代价是成本高 1.5%–5%，makespan 比 static30 高 3.7%。
- **F PPO-DAC：** 对最强的 NoRL（按 λ 从 61 种配置里挑最优）：成本 −0.09%（1 s、λ=0，p=0.007）；目标值 −0.46%（0.3 s、λ=1，40 胜 10 负，p=0.002）；HV +0.4%，不显著。对作者 TSALNS：HV +31%–37%，成本 −3%–5%，50 个算例全胜。A2C 基本没学动。开环蒸馏消融显示，提升主要来自 PPO 发现的分段搜索安排，而不是在线自适应（F4）。
