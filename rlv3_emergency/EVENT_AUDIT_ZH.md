# 事件、物理资源与基线审核

本轮只修复 c193b0d 研究包的工程实现。手写几何、反例和极小地图属于工程检查；没有运行历史科研地图、训练、作者求解或质量比较。

## 已修复的问题

1. 原同步动作执行会在公共时间仍为出发时刻时写入未来位置、电量和服务完成，其他无人机与策略因此提前读到未来。现在所有已起飞无人机在同一公共时钟按不超过 0.5 min 的段推进；先推进所有在途状态，再开放当前节点决策。未来订单不进入可选集合。
2. 请求拥有独立外生发布时间。一个请求在另一架机飞行期间发布，会在精确发布时间唤醒空闲机；飞行/服务不被抢占。场景仅支持“到节点后决策”，不宣称任意在途改向。普通巡检与同塔复检是不同服务任务，不互相抵消；同时请求按独立 rid 计数、claim 排他。
3. 原 T_HARD 之后解除风/雷暴屏蔽与“晚间必完成”逻辑删除。没有 skip 不等于物理全完成；天气、资源、日界或无可行续接均可导致未完成。全部未完成项与失败机进入有限 J 惩罚，不把失败路线当成低成本胜者。
4. 预测任务屏蔽与 RETURN 屏蔽均核算本段、服务、实际返站所需电量，剩余累计 flight+service duty，以及 600 min 工作日。电池仅在实际抵达原站后归零；累计 duty 不归零。工时上限直接使用 layout 的官方站型 duration，不按机槽二次覆盖。
5. 真实能量/工时耗尽、不可保持航向、超运行风限制或雷暴穿越使原位置任务失败；删除强降后瞬移原站、60 min 免费恢复并补电的路径。真实雷暴连续轨迹检测用于去程、固定位置服务和返程；关闭预报 cell shield 也不会关闭真实事故统计。动态风仍采用离散积分；碰撞在当前积分段被发现，未宣称精确首次接触定位。
6. A 的 nowind / fixed_e4 / fixed_n8 对应 W00 / W04E / W08N。服务能量保持原 node.en，按 node.en/node.svc 积分；风只通过风三角改变飞行时间与 P1*time。固定风资源链与独立作者锚审核口径一致。动态天气原型不冒充同风完整作者求解。
7. 跨站接单仅用于已发布复检请求，资格为已部署站覆盖半径加同一物理资源屏蔽，各方法同权。常规巡检保持原固定站归属；部署、机数、容量、归属与固定费用不改。49 个及更多可见候选全部传入动态注意力接口，没有 nearest-48 静默截断，也不依据未来订单规模筛选样本。
8. 原结果把未覆盖请求和未完成请求剔出分母，已纠正。n_urgent/high_total/norm_total 含完整冻结发布流，无资格请求仍为失败。routine_done/routine_total 单列。到场与服务结束分别记录 t_arrival、t_done。

## 指标定义

- A 主指标 M_return：从公共 0 时刻至最后一次实际返站的分钟数。只在全部机实际回原站且无失败时有值；未回站为 null，不用最后巡检时间、飞行工时总和或恢复时间冒充。all_returned 和 physically_feasible 单列，complete_strict 同时要求全任务完成、实际返站、资源合法、无超时。
- B 主指标 high_on_time/high_total：高优先请求到场不晚于 release+20 min，且随后完成服务的数量 / 全部已冻结高优先发布请求数量。norm_on_time/norm_total 同理，窗口 60 min。服务结束晚于到场 SLA 本身不构成迟到；到场后服务失败不记成功。
- resp_mean/resp_p95 只描述实际观测到场响应，并同时给 response_observed/response_missing。completion_response_mean 描述完成服务响应。上述条件均值不替代全发布分母的主指标。零高优先请求保留为 N/A。
- J 为固定成本 + TIME_COST*(真实飞行+服务) + 事故罚项 + 到场迟到罚项 + 每个未服务项 1000 + 每架失败机 1000。J 是辅助有限训练目标，不替代 A 的返站目标、独立同风成本 cap 或 B 的全发布时效。跨站复检不伪装为独立站奖励；训练使用全局目标。

## 请求分布和信息范围

emerg_random_low/mid/high 使用纯均匀时间 Poisson 背景；emerg_clustered_low/mid/high 使用背景与空间邻域成组触发的合成混合流。三档目标期望负载为每塔 0.05/0.15/0.30 请求/班，均为场景假设。成组子请求延时按剩余发布窗口条件指数采样，不因边界丢弃而降低标称期望负载。两类流使用不同且可复现的种子标签，生成器完全不读路线或策略动作。

make_env 在任何动作前冻结 layout、天气对象与完整请求流的 SHA256，供注册/评价匹配。该哈希不作为 actor 输入。resample_future 仅是隐模拟状态条件重采样，不是经验证的公共历史条件信念采样；原始复检未来重抽也不等于对成组过程的正确后验。RI 在其他模块被阻止，直到独立验证公共信息采样器。该工程修复不授予 RI 无偏性或新颖性。

## REOPT 的实际算法与预算

REOPT 名称仅为兼容规格别名，实际是自写 cheapest insertion + relocate + 2-opt + 相邻趟 merge；不是作者 TSALNS、不是 ALNS，也没有“最强非 RL”认证。每次起趟重规划；新请求仅在下一节点按 EDF 头插，不宣称每次发布就重求完整路径。规划只使用已发布任务和预报。

不再把不可行单点趟停放到机 0，也不把一架机的趟复制到另一架异构机。候选调度按每架真实剩余累计 duty、返站与电池检查；未安置节点显式留在 unassigned。每次重规划采用 monotonic 合作式名义截止，预处理与实际全部规划时间都记录；Python 内部检查不是强制硬墙钟。policy_compute_s 记录全部动作决策时间，planner_records 记录算法、名义预算、实际时间和未安置节点。生产评价另用外部进程从冷启动至退出的共同硬墙钟；不得把 0.03 s 内层预算冒充整图公平预算。
