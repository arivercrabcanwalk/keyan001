# 论文 B · 无风下的紧急复检

**版本：审查 c193b0d 后的开发版。** 固定原作者站和机队，风为零、没有雷暴。所有常规任务保持原设施与站归属。上线后新增的是原塔复检，不是投递、医疗或新站建设。[实验与服务器说明](../rlv3_review/REVIEW_ZH.md)。

| 冻结项 | 解释 |
|---|---|
| 外生需求 | `emerg_{random,clustered}_{low,mid,high}` 六格。前者独立随机，后者有聚簇；三档是情景负荷，不是实测故障率。20/60 分钟为高优/普通**到场**时限，非临床或行业认证 SLA。以独立请求 ID 记账；没有拒单动作，不代表不可能失约。 |
| 执行资源 | 所有方法在同一固定部署运行。只有已发布的复检可跨原覆盖站调派；在塔上不等于有可调飞机、电量和工时。飞行段不可中途改向，到达节点再决定；外生发布会唤醒可用机，在途与服务中的物理状态按时钟推进。本站换电/趟间周转按照本模型约定，不能解释为已标定的实地换电调度。 |
| 主效应 | 在常规巡检全部完成、飞机实际返站、没有物理失败、每格成本守界前提下，比较**及时到场且最终完成服务的高优复检数 / 全部已发布高优复检数**。0/N 是 0，N=0 为 N/A；不能把少接或漏服务带来的低费用算优势。迟到、未到场、未完成分别留数。普通准时率、响应分位数、成本与 J 单报。 |
| 学习与对照 | 集中式物理动作、同一屏蔽和候选。默认 BC + REINFORCE/LOO；B 验证选择看合并高优准时率、以 J 破平，代价 J 仍是训练代理。比较 A1、GREEDY、局部 REOPT、各自调参版、BC-only、相同策略去提示、随机初始化与标准 PG。要主张优于所有强在线方法，另需同信息条件情景前瞻，而不是用真实未来扮演在线教师。 |
