# rlv3-weather 设计文档（论文 A：原论文场景 + 天气）

> 命名：本系列从此称为 **rlv3**（后续 rlv4、rlv5…），与旧的 wx*/e2e_v* 名称完全分开。
> 本文件夹只研究 **Liu et al. (EJOR 2026, 334:285–300) LRPHSD 原场景 + 天气（物理风场 + 移动雷暴禁飞区）**；
> 紧急任务是另一篇论文，放在 `rlv3_emergency/`。天气 **全部为合成数据**（固定规则）。所有数字只能来自运行结果，本文不含任何实验数值结论。

## 0. 一句话
在作者 TSALNS 给出的 **同一选址、同一机队、同一目标-站分配** 下，学习一个 **弧级（逐节点）在线调度策略**：
无人机每到一个节点就决定“下一个塔 / 返航换电 / 原地等待”。真实转移由 **物理能耗模型** 积分得到（非神经网络拟合），
状态里注入 **物理特征 η**，动作由 **能量守恒硬约束 + 雷暴预测** 屏蔽（shield），奖励只用 **真实目标 J**。

## 1. 吸取的教训（为什么这样设计）
| 以前的问题 | 本设计的对策 |
|---|---|
| v3 ES-RL 靠“跳过巡检”刷奖励（reward hacking） | 动作空间里 **根本没有“跳过”**；episode 只有在全部计划塔都巡检完才结束 → 严格 100 % 完成是结构性的，不是罚函数；单元测试 + 闸门 G0 双重检查 |
| e2e v2 的“增益”来自多开站 | 站点/机队/分配直接取作者 TSALNS 方案，RL 无任何开站动作；每条结果写入 #站、#DABS、固定成本，闸门 G1 逐实例比对 |
| 天气场景中作者方法不能 100 % 完成 | 完成性由共享可行层保证（返航-等待-晚间降风 + T_HARD 之后禁止空等），所有方法共用 |
| “风大时 RL 等一等”的收益可能来自建模漏洞（晚间降风） | 降风只在 10 h 工作日结束（T_DAY=600 min）之后开始，而此后每分钟按 C_OT 罚超时 → 不可能免费利用 |
| 单一启发式对照太弱 | 对照组：作者原样执行 A1、A1-T（dev 调参的风险余量）、GREEDY-T、**REOPT-T（以作者方案热启动的滚动重优化 = 作者方法的“事件触发重优化”适配）**、REOPT-W-T（再加等风阈值）；全部在 dev 上调参，test 前锁定 |

## 2. 场景（最终敲定）
* **地图/方案**：作者 50 张测试图（35/50/65/80/110 塔各 10 张），作者 TSALNS 10 s 方案 `data/plans/test_ts.jsonl`（与 report3 表 2 同一批）；dev 20 图（`dev_ts.jsonl`）；训练图 200 张（`data/instances/train`，由 run_all 现场用作者 TSALNS 10 s 求解）；泛化：fresh 50 张新图。
* **作者参数原样**：v=15 m/s，p1=0.018/min，p2=0.020/min，t_f=10 min，Q_l=1、Q_s=0.81，R=5/4 km，作者“每机累计作业时间”上限 600/480 min（超出按 C_OT 罚），成本 = 固定成本 + 0.5 元/min ×（飞行+巡检分钟）。
* **一天**：班次 H=480 min；10 h 工作日 T_DAY=600 min（之后每站每分钟 C_OT=1 元）；T_HARD=660 min 后进入“必须完成”模式（禁止空等、去掉方法自加的余量）。
* **天气（合成）**：平均风 + 中尺度相关场 + 隐藏阵风 + 小时级预报 + 移动雷暴单体（见 §3）。雷暴单体 = **会移动、会生长衰减的临时禁飞区**：真实闯入 = 安全事件（计入 J，C_INC=200 元）并触发返航。
* **执行**：真实风下以 0.5 min 步长积分；飞控智能返航（RTH）：剩余能量 < 真实返航需求 ×(1+|w|/v_a) 时立刻返航，本塔未巡检、回到任务池（中止）；返航途中电量耗尽 = 迫降事件（+60 min 回收）。零风时 RTH 系数为 1，作者可行航次永不触发（单元测试）。
* **目标 J** = 作者成本 + C_OT·超时 + C_INC·安全事件。论文主表按作者原生指标（成本、固定成本、站/DABS/无人机、飞行距离、架次、飞行+巡检分钟、完成率）+ 中止/安全事件/超时 + J。

所有天气由 `stable_rng(seed)` 决定；训练种子 1,000,000+、dev 50000–50019、test 90000–90099，互不重叠。

## 4. 物理 AI（对用户图片第 8 节的核查与修正）
### 4.1 能耗模型（8.1，环境真实转移函数，不做 NN 拟合）
旋翼功率-空速曲线（Zeng, Xu & Zhang 2019, IEEE TWC 18(4):2329, doi:10.1109/TWC.2019.2902559）：
P(V) = P0(1+3V²/U_tip²) + Pi(√(1+V⁴/4v0⁴) − V²/2v0²)^{1/2} + ½d0ρsA·V³（桨叶型阻 + 诱导 + 寄生）。
形状常数取 Zeng 默认值，用两个缩放系数 **闭式标定** 到作者参数：P(0)=p2=0.020/min（悬停）、P(15 m/s)=p1=0.018/min（巡航）。
标定后寄生项系数 β≈1.42（带云台载荷的巡检机阻力更大，合理），**无风最大航程速度≈16.5 m/s，与作者“15 m/s 最优”（Cai et al. 2025 实测）一致**——这是独立的一致性检查。
风只通过运动学进入：无人机保持空速 v_a=15 m/s 并偏航修正，
η = (w·u_ij)/v_a（顺风为正），ξ = (w×u_ij)/v_a，v_g = v_a(η + √(1−ξ²))，
**c_ij^wind = P(v_a)·d_ij / v_g**；巡检悬停能耗 = P(|w|)·t_f（悬停即以空速 |w| 飞行）。零风时 c_ij = p1·d_ij/v，悬停 = p2·t_f，**与作者完全一致**（单元测试：解析式、积分器、70 张图官方评估器逐图相等）。

图片公式 c = d/v_a·[P0(1+κv_w²) + W²/(v_a(v_a−v_rel))] 的问题：
1. 用空速而不是地速计算时间，风永远不改变飞行时间（运动学错误）；
2. v_rel = v_w cos(θ_ij−θ_w) 时 v_rel>0 为顺风，W²/(v_a(v_a−v_rel)) 却让 **顺风更贵**，并在 **顺风=空速** 时发散——符号/奇点错误（`phys.sketch_cost` 原样复现，单元测试记录）；
3. P0(1+κv_w²) 把桨叶型阻项用在风速上，物理上应是空速。
保留图片的意图（型阻 + 诱导 + 风）但换成上面的标准形式；奇点处理：|ξ|≥1 或 v_g < 4 m/s 视为物理不可行，直接屏蔽。
其他文献对照：Dorling et al. (2017) IEEE TSMC doi:10.1109/TSMC.2016.2582745（悬停功率）；Liu, Sengupta & Kurzhanskiy (2017) ICUAS doi:10.1109/ICUAS.2017.7991310（含风的功率模型）；Zhang et al. (2021) TR-D 90:102668 doi:10.1016/j.trd.2020.102668（模型比较，作者亦引用）；Kirschstein (2020) TR-D 78:102209 doi:10.1016/j.trd.2019.102209（风使能耗显著上升）；Thibbotuwawa et al. (2020) Sensors 20(2):515 doi:10.3390/s20020515（风不确定下的机队任务规划）；Cheng, Adulyasak & Rousseau (2024) MSOM 26(4):1402 doi:10.1287/msom.2022.0339（风影响飞行时间的鲁棒调度）。
实测数据（可选外部验证，不用于训练）：Rodrigues et al. (2021) Scientific Data, doi:10.1038/s41597-021-00930-x，数据 doi:10.1184/R1/12683453（DJI M100 209 次飞行，含风速与功率）。

### 4.2 物理特征（8.2）
每个候选塔 j：η_ij、ξ_ij（当前预报）、η_jD（返航段）、η_ij(+30 min 预报)、η_ij(机载实测风)、预测 c_ij/c_jD/悬停能耗/总需求/执行后余量（均除以电池容量）、雷暴外推最小间距；上下文：预报风（现在/+60 min）、实测风、实测−预报差、活跃单体数、时间、电量、工作量/剩余时间比等（`feat.py`，只用决策时刻可观测信息；隐藏阵风与真实未来风不可见）。

### 4.3 物理动作屏蔽（8.3，能量守恒硬约束 = shield）
允许 j 当且仅当 c_ij^wind + 悬停_j + c_jD^wind ≤ e_remain（预报风，余量 0，正是图片的不等式），且 i→j、j→D 两段不与外推雷暴（+缓冲）相交，且预报风 ≤ 12 m/s。屏蔽对所有方法相同；RL 通过 logit 置 −∞ 实现（Huang & Ontañón 2022, FLAIRS, doi:10.32473/flairs.v35i.130584；shielding 思想见 Alshiekh et al. 2018 AAAI doi:10.1609/aaai.v32i1.11797）。
预报有误差，所以硬约束只能保证“按预报可行”；**风险余量** 由各方法自己决定：启发式在 dev 上网格调参（0–50 %），RL 自己学（这正是 RL 的价值点之一）。真实风下的保护交给飞控 RTH，并把中止/安全事件计入 J。

### 4.4 奖励（8.4）——不采用图片的顺/逆风奖惩
图片中 p_head∝−η、r_tail∝+η 不是势函数差（Ng, Harada & Russell 1999 ICML 的 PBRS 条件），会改变最优策略：策略可能 **专挑顺风长航段“刷分”**、或为了顺风奖励多飞，典型 reward hacking。
本设计奖励 = −J（真实成本、超时、安全事件），E_remain = E_init − ΣPΔt 已经在环境里精确积分（电池耗尽 → 迫降事件）。
在本训练方式（同组多次 rollout 共享均值基线）下，任何势函数整形都在整条轨迹上抵消，因而没有必要；图片的 η 整形只作为 **消融 ABL_eta** 运行，用来实证“它不带来真实收益/会扭曲行为”。

## 5. RL 技术选型
* **决策粒度**：弧级（每到一个节点决策一次）而不是整航次——图片的 c_ij、η_ij、能量不等式都是弧级量，弧级才能“重新排序/拆分/等待/避开单体”。
* **网络**：候选集注意力指针网络（Kool et al. 2019 ICLR, arXiv:1803.08475；POMO 编码-解码风格），每次决策重编码（特征全是动态的）；3 层 Transformer、128 维、8 头，约 0.6 M 参数。
* **训练（三阶段，最终版）**：
  ① **行为克隆（BC）** 模仿 dev 调参后最强的非 RL 方法（教师，自动选择），并把教师在当前状态的选择作为一个 token 标记输入网络（“学习改进启发式”，教师以影子模式同步运行；测试时同样可用，不看未来信息）；
  ② **滚动改进（Rollout Improvement, RI）= 近似策略迭代 + DAgger**：用当前网络贪心驾驶整天（DAgger 状态分布，Ross et al. 2011 AISTATS），随机抽取约 8 % 的决策点，对模拟器做快照，把“教师动作 + 网络前 3 个备选动作”各自用教师启发式跑完全天，取 J 均值最低者为标签（只有优于教师动作 >0.5 元才替换）。**每个候选在 R=3 个“重新采样的未来”上评估**（`Env.resample_future`：t 之后的湍流/阵风/预报误差从当前状态继续随机演化、尚未生成的雷暴单体重新抽取；紧急任务场景中尚未出现的请求重新抽取），3 个未来在候选之间共享（公共随机数）。这就是随机动态规划中的 rollout 算法（Bertsekas, Tsitsiklis & Wu 1997 J. Heuristics 3:245；Secomandi 2001 OR 49(5):796；Goodson, Thomas & Ohlmann 2017 EJOR 258(1):216）的学习版：rollout 策略在期望上不劣于基准启发式，网络学其可观测部分。**为什么必须重采样未来**：本地试跑的第一版直接用真实未来（“后见之明”标签），网络学会了“侥幸”的冒险动作，dev 上安全事件从 0.06 升到 0.20、J 变差（730.4 → 769.8，20 图×4 天，小样本试跑）；改为重采样后消除了这一信息泄漏。已出生雷暴单体的后续轨迹抖动仍沿用真实值（小残余偏差，论文中说明）。**保守接受规则**：只有当备选动作在全部 R 个采样未来中都比教师动作至少好 1 元（配对、公共随机数）时才改标签；RI 拟合时同时回放 4 万条 BC 样本，防止遗忘（未加回放时试跑中 dev 回退率从 0.025 升到 0.225）。**本地 CPU 小规模试跑的真实结果（天气，仅作可行性证据，不是论文结果）**：dev 20 图×4 天，A1 J=1114.0，REOPT@0.05 J=1079.7，BC J=1079.8，RI 10 轮后 J=1079.8（约 6 % 的抽样决策被改标签，贪心策略尚未改变）——即在试跑规模下 RL 与最强基线持平，正式实验的改进幅度未知，需如实报告。
  ③ **多 rollout 策略梯度微调**：同一张图、同一天气（公共随机数）跑 N=8 条采样轨迹，用组内均值做基线（POMO 共享基线，Kwon et al. 2020 NeurIPS, arXiv:2010.16011）；**每个站单独计算回报**（纯天气场景中各站互不影响 → 精确信用分配）；熵正则 0.01，梯度裁剪 1.0。本地试跑发现：仅靠 ①+③ 时，策略迅速收敛回教师（偏离教师的随机探索几乎总是变差，熵→0，dev 不变），这正是加入 ② 的原因。
* **为什么不是 PPO/MAPPO**：本问题是“有限时域 + 组合动作 + 有精确模拟器 + 可重放同一随机种子”，POMO 式公共随机数基线比学习价值函数方差更低、无需评论家；多机协作在纯天气场景下只发生在同站两机之间，参数共享的单策略已覆盖（MAPPO，Yu et al. 2022 NeurIPS arXiv:2103.01955，作为讨论）。
* **约束**：完成率、站点由结构保证，不靠拉格朗日乘子（RCPO / PID-Lagrangian 只在约束无法结构化时才需要）。
* **checkpoint 选择**：dev（20 图×10 天）上 J 最低且 **每个 dev episode 都严格 100 % 完成** 的检查点；BC 检查点本身也参与选择。
* **测试**：贪心解码（~1 ms/决策），不使用真实未来天气。

## 6. 对照组（全部同一模拟器、同一屏蔽、同一完成层）
| 名称 | 含义 |
|---|---|
| A1 | 作者 TSALNS 方案按原顺序执行（被屏蔽的塔：在途则返航，在站则跳到计划中下一个可行塔/等待） |
| A1-T | A1 + dev 调参的风险余量 |
| GREEDY-T | 物理感知最近邻（最小预测能耗）+ 余量 |
| REOPT-T | **最强非 RL**：每次出航前，以作者剩余方案热启动，用当前预报的物理代价对本站剩余任务做插入 + relocate/2-opt/合并局部搜索（ALNS 式修复-改进），= 作者方法的“事件触发重优化”适配 |
| REOPT-W-T | REOPT-T + 风速等待阈值（8/10 m/s） |
| BC_s0 | 只做行为克隆的网络（衡量 RL 微调本身的贡献） |
| RL_s0/1/2 | 本文方法，3 个种子 |
| ABL_nophys | 去掉 η/风特征（检验 8.2 物理特征的价值） |
| ABL_eta | 加入图片的 η 顺/逆风奖励整形（检验 8.4 的风险） |
| ABL_nobase | 纯端到端：不给网络显示教师建议（检验“学习改进启发式”这一设计的贡献） |
“最强非 RL 对照”= dev 上 J 最低的调参族（预先写入 `tuned_weather.json`，不看 test）。

## 7. 指标与预注册闸门（analyze.py 自动判定）
* G0：所有方法、所有 test episode 严格 100 % 完成（否则整组结果作废）。
* G1：同一地图上所有方法的 #站、#DABS、#无人机、固定成本完全相同。
* G2：RL 的 J 显著低于 A1（配对 Wilcoxon，Holm 校正 p<0.05，≥2/3 种子）。
* G3：RL 的 J 显著低于最强非 RL（同上）。
* G4：RL 安全事件/episode 不高于最强非 RL + 0.01。
* 报告：均值、相对 A1 %、地图聚类 bootstrap 95 % CI、胜率；分场景（混合 / 全雷暴日 / 只有风 / 风×1.3）和 fresh 新图泛化。
任何闸门不通过都如实报告，不改口径、不重选测试集。

## 8. 风险
| 风险 | 说明 / 缓解 |
|---|---|
| RL 对最强 REOPT 的优势可能很小 | 预期收益来源：学到的风险余量（中止↔拆分的权衡）、雷暴附近的时机选择、风向感知的排序；若 G3 不通过，论文仍可报告“物理屏蔽+物理特征”相对作者执行的收益与安全性，诚实写明 |
| 安全事件方差大（200 元/次） | test 5000 个配对 episode + 地图聚类 bootstrap；单独报告事件率 |
| 合成天气的外部效度 | 参数均有文献锚点；风×1.3 敏感性；可选用 Rodrigues 2021 实测数据检验能耗模型形状 |
| 训练时间 | CPU 并行 rollout 为瓶颈；`RL_H` 可调，所有阶段可断点续跑 |
