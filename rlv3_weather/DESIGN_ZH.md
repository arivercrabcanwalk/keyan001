# 论文 A · 天气下的巡检路线

**版本：审查 c193b0d 后的开发版。** 零紧急任务。此版本不提供 RL 已胜出或真实飞行安全的证据。先看[实验与服务器说明](../rlv3_review/REVIEW_ZH.md)。

| 研究层 | 所测问题与边界 |
|---|---|
| 已知恒风、原简单能耗 | 同一张底图设 `nowind`、`fixed_e4`、`fixed_n8`（分别为无风、向东 4 m/s、向北 8 m/s），每一格要求完整同风作者解。固定启用站、站型、机队、目标归属，学习只选塔、返航或站内等待。逐图同风作者原费用上限 +1e−7，第一指标为实际最后返站时刻 `M_return`（分钟）。全机队累计作业时间、费用、J 另报。不能把不同风当独立新地图。 |
| 动态风场、移动雷暴 | `weather_paired_clear` 与 `weather_paired_cells` 保留完全相同的真值风、出流风和预报，只改禁入规则及其显式观测；不能解释成“移除了实际雷暴”，也不能分离禁区信息与行动限制的效果。此配对仅工程资格。历史 `weather_wind` 和 `weather_storm` 是两种不同分布，不作单因素对照。动态条件用显式运营预算。 |
| 算法与对手 | A1 是随环境执行的作者顺序，GREEDY 是预测贪心，REOPT 是以作者剩余航次初始化的局部插入/重排，不是重新运行原 TSALNS，更不是已证最强。比较各自验证选择的调参版、BC、无教师提示、无物理特征、随机初始化及标准 PG。对 F3 的正式主张还须原生强 min-max ALNS 和独立共同 H。依赖同一个共享后处理时，必须给各臂计入相同预算。 |
| 学习目标 | 默认 BC + 独立多轨迹 REINFORCE/LOO，不是强制多起点 POMO。PG 的 J 是费用与失败代理；固定风先逐图核对作者 cap 再按平均 M_return 选择 checkpoint/对照；动态组按资格后 J 选。η 仅作输入，主方法不加风向奖惩；未经资格审查的重采标签禁用。 |

[数学与适用域、同风作者收据和 CLI](PHYSICS_AUDIT_ZH.md) · [学习链与反例](LEARNING_AUDIT_ZH.md)。完整 Zeng 曲线不等于两机型经实飞标定；原测试的70个断言比较的是静态方案总费用，不是70张图的逐段电池测量。未完成独立实测、已发预报回放和强对照资格前只报告模拟合同结论。
