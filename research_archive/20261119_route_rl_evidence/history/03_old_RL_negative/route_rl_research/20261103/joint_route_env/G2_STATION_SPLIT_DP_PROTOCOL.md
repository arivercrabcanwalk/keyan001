## Mathematical reference and numerical boundary

For each complete station union T_s with n<=12, use Held–Karp to find one minimum-length closed station-rooted tour for each nonempty subset Q, recording parent pointers. Time(Q)=length/speed+sum(service); energy(Q)=length/speed*flight_energy+sum(target_energy). For each eligible slot, subset partition DP minimizes total trip minutes over disjoint nonempty battery-feasible subsets; a pivot removes only trip-list permutation symmetry. Battery and per-slot cumulative duty are enforced; RETURN never resets cumulative duty. Objective and duty use the same operating minutes, so one minimum-time scalar per subset suffices in the mathematical recurrence. DABS enumerates every LD subset A, including empty/full, with SD=T_s\A, and enforces separate duty limits.

kind0: no routes/targets. SABS kind1: SD slot1 only; small battery/radius/duration. DABS kind2: LD slot0 large battery, SD slot1 small battery; BOTH use large station radius/duration. Empty slots have [] trips; no empty trip is emitted. Coverage is independently checked with the original evaluator.

Compute BOTH (a) reference restricted to the parent's fixed slot owners and (b) joint-slot reference using the same full station union cutoff. Do not solve individual small slots of an oversized union and call that a joint reference. Fixed-owner then joint is the frozen per-station order; they share the map wall deadline, but each has its own transition/state limit.

This is exhaustive DP under a frozen floating-point recurrence. Additive real-arithmetic reasoning does not establish equivalence to every evaluator IEEE summation/order or boundary case. Even COMPLETE_*_REFERENCE means an exhaustively computed numerical reference with independently validated witness, NOT a strict real/IEEE global optimum certificate. Store DP scalar, evaluator operating minutes/cost and residual independently.

Frozen arithmetic: DP edge lengths use sqrt(dx**2+dy**2) like evaluator trip lengths; Held–Karp accumulates open path edges in visit order and adds the closing edge last. Target service/energy subset sums add the low-bit target after its smaller-mask sum; partition time is trip_cost[sub]+dp[remaining], with ascending mask enumeration, descending submasks and strict-less-than first-encountered tie choice. These subset/partition accumulation orders may differ from the evaluator reconstruction order, so numerical-reference status remains qualified. Coverage predicate uses literal hypot distance>radius+1e-7, and battery predicate uses literal energy<=battery+1e-7; every full witness is still independently rescored. Numerical constants have distinct roles: 1e-7 is ONLY the evaluator's battery/coverage/duty feasibility convention; 1e-8 absolute full-cost residual is DP-to-witness reconciliation; 1e-8 absolute full-cost parent regression is a separate implementation screening threshold. Store raw differences, including tiny negative values, and raw signs; never round an effect to zero. A regression beyond threshold, residual failure, malformed witness or evaluator rejection yields NUMERICAL_OR_IMPLEMENTATION_UNRESOLVED. Keep the rejected witness and diagnostics. No silent repair, clipping or EPS adjustment. For unresolved rows the separately assembled feasible partial incumbent explicitly retains parent routes and is labelled as such, not as that station's DP optimum. Any slight accepted regression is also visible. Known numerical uncertainty cannot support an opportunity upper bound.

## Frozen compute bounds and clocks

n<=12 is a NEW station-union computational cutoff, not a claim that historical whole-instance DP validated this station implementation. At most 4096 masks; conservative dense allocation-cell estimate (5*n*2^n)/2+11*2^n+n*n+4*n+128 <=180000 per reference; all allocations are made only after this hard structural check. Transition cap=2,000,000 per reference. WorkBudget checks entry, at <=1024-transition intervals, and completion. Parent-pointer output is bounded by n and cells. These are explicit allocation/cell limits, not an OS-level resident-memory guarantee; peak Python allocation and process RSS are also recorded without calling them a hard OS cap.

Per-map DP scheduling deadline=12 seconds, starts before instance hash/read and Greedy construction. No new station reference starts after that deadline. Running DP exits at the next bounded check. Independent validation and durable serialization still complete after the deadline if necessary and are charged: record actual end-to-end seconds and cap overrun, never call it a hard 12-second end-to-end solver. Batch scheduling deadline=360 seconds; remaining maps still receive hash/parent/status/output, no new DP. There is no performance ranking against archived 6s/12s timings. Preserve size, state, transition, deadline, memory/error and infeasible outcomes separately. No changing order/bounds or rerunning to seek a positive result.
