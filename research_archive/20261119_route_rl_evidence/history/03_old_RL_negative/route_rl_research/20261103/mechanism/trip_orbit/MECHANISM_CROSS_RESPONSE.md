**The fixed-consecutive-window statistic is a genuine partition.** Fix c before sampling. Map a successful trajectory to the ordered tuple of unordered sets of each consecutive c completed, slot-tagged ordered trip blocks, with a final shorter window. Every trajectory has one cell; permutations inside a window remain in the cell, while cross-window moves change the statistic. Because all earlier window block sets are fixed and the closed boundary state is canonical/history-free, each window starts in a fixed state. Summing its internal block orders yields Z_w, and the cell likelihood is the product of these Z_w. Scores therefore add. This satisfies the partition requirement that an arbitrary order-dependent peer selection would fail. My warning excludes unproved peer windows, not this explicit statistic.

**Full physical-action normalizers and failure identity cells are required.** A replay query obtains the probability of its desired physical action under all the actor's actual legal alternatives, including actions belonging to other trip collections. Renormalizing only over future blocks in the sampled cell changes the policy. A deterministic final RETURN or STOP contributes1 only if the sampling actor actually makes it deterministic. Failed or unfinished sampled trajectories remain finite-reward identity cells with their original score; filtering or resampling them conditions on success and changes the target.

## Accepted independent additions

The adversary supplies a useful exact memory tradeoff: forward/backward posterior edge occupancies q(A,j) can be detached coefficients of logw in a recomputed-gradient surrogate. At current theta this gives the marginal score. Differentiating through q in that surrogate adds unwanted terms; direct differentiable log-sum DP remains valid. This is standard forward/backward marginal-score machinery, not another novelty claim.

For window w containing m_w blocks and N_w target visits, direct physical-action queries number `(N_w+m_w)*2^(m_w-1)` before multiplying by network, mask, state reconstruction and backward costs. A constant c bounds the exponential factor but does not make actor inference free. Explicit parameter-score storage can cost O(2^c*P); ordinary autograd activation storage differs and must be counted. A raw trajectory control gets matched total training compute, not merely the same sampled episode count.

I accept that c=2 and c=3 generally define nonnested partitions. Larger c does not imply monotone variance reduction without an actual coarsening relation. The full orbit is coarser than any fixed-window partition, while c=1 gives singleton successful paths. The law-of-total-covariance result is per sample at fixed parameters; it does not prove lower optimization error per second, improved Adam/PPO behavior or better routes. Parameter-dependent hard masks, stateful noise and old-policy replay remain outside the simple differentiable on-policy derivation unless separately treated.
