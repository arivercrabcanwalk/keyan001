# P3：成本保护下的目标完成时延研究

日期：2026-11-03。本修订依据用户允许引入其他评价指标、已批准执行优化、要求成本接近作者且RL实际有作用的最新指令。修订发生在新研究地图及路线质量结果均为零时；不改写已批准的P2.1或历史证据。

## 唯一主要终点及范围

主要终点为全图平均目标服务完成时间 `MTC = sum_i C_i / N`，单位分钟，对应独立评分器 `mean_target_completion`。每架无人机从时刻零开始，同机的趟次按保存次序串行执行；目标完成时刻包含先前完整趟次及当前趟次至该目标服务结束的飞行和服务。当前趟次后续返航不计入该目标时刻。继续采用原模型零换电/排队/启动延迟。`M_return` 为必报作者可比次终点，p90为描述性次终点；二者不能替代主要终点。

MTC是已有minimum-latency目标在本问题的评价，不主张新指标类别或首次LRPHSD评价。固定部署、站型和目标到站归属，允许站内机型归属、目标顺序和分趟联合决定；仅支持D条件路线改进主张。RL输出只有物理 `(slot,target)/(slot,RETURN)`；任何算子/算法/邻域/预算选择均不属于主线。

共同锚点为每张新图上预定单seed的J1b作者完整可行输出。各方法必须逐图满足完整原模型可行性及 `C <= C_J1b + 1e-7`，epsilon=0；保留固定及运营成本、原始成本差。M_return仅必报，不额外暗设不增约束。所有方法获取同一锚点、信息、物理域和6s/12s路线改进总墙钟，作者锚点生成时间另报。固定域条件比较不冒充整个TSALNS同总墙钟端到端胜出。

## 数据与冻结顺序

复用已验收V6/semfix，不重跑完整复现。官方120图、旧Stage A、12000整图拒绝pilot提案以及全部已暴露手工工程夹具保持排除身份。新生成器为constraint-reconstructed顺序条件提议，不是Liu原生成器复现，接受点不称IID。SplitMix64只用于可重放伪随机实现；有限网格接受概率界的独立均匀模型假设单独披露。

12个公开(J,I)家族，各预分配4张opportunity（共48）、1张calibration和1张validation（共24）。v2命名空间固定为 `route_rl_G23_sequential_MTC_20261103_v2`。坐标seed及目标标签seed分别从命名空间、family、partition、ordinal、purpose的规范JSON SHA256派生；target标签用无模偏Fisher-Yates随机化。每个site至多32提议、每target至多1024提议；任一上限耗尽或暴露身份碰撞即该预分配槽失败，不补槽、不换seed。地图文件、私有placement侧录及metadata均保存，求解器只获得五列实例。

在首次生成研究图前冻结本协议、生成器、排除集合、72槽分配、作者J1b/J2b源码和二进制身份、作者seed算法/命名空间、评分器、完整比较族、参数、执行器和统计规则。所有哈希记录在FREEZE.json。工程修复必须版本化保留失败并说明受影响数据；不得把修复后的重复运行隐去。

J1b是唯一主锚点；J2b只作固定参数敏感性，不按图选择二者较好者。作者seed命名空间固定 `route_rl_G23_author_anchor_20261103_v2`，具体signed64转换使用原author_runner.seed_for_input；每张图每profile一次，180s超时不以部分best补作合格锚点。J2b优先仅在24隔离校准/验证图运行，费用仍计总账。

## 同目标比较族

1. 原始J1b完整解（no-op作者锚点）。
2. `smith_trip_order`：固定slot和每趟内容/方向，按完整时长/目标数升序排序，是标准Smith规则，成本和M_return不变。
3. `joint_mtc_vnd`：完整MTC序列感知下降，覆盖insertion/relocation、reversal、target swap、split/merge、合法slot重分配和趟次顺序。
4. `joint_mtc_ils`：相同物理域的固定seed迭代搜索。预定 `max_evaluations=12000, max_perturbations=8`，seed从map SHA和 `route_rl_G23_MTC_nonRL_20261103_v1`派生，不择seed。
5. 作者路线组件续跑：只调用冻结J1b的原ALNS及load-balancing repair，在每站原归属子实例内运行，明确区别于完整TSALNS；外部以完整MTC及原成本cap保存best。此组件及其工程验收未交付时，G3保持未完成，不能宣称已比较全部强基线。

全部参数在质量结果前锁定。本轮不使用48机会图调参。非RL最强配置的预定选择规则：在12 calibration图按等权平均MTC降幅排序，跨两预算平均后决定候选；validation只做一次核查，不用于继续调参，失败则G3不通过。最终G4/Formal必须同时胜该冻结候选及所有预登记确认强对照，避免用弱候选。若某方法配置完全相同，24图仅用于校准/可靠性，不能挪作独立确认样本。48图是新机会/开发数据，非正式测试。

G4还须同state/action/mask的greedy、beam或BC和普通直接路线RL控制。其代码、模型、至少3独立训练seed、训练样本身份、资源、checkpoint选择及机制消融必须另行冻结；本轮工程或非RL结果不自动放行训练。已NO-GO机制不改名复活。固定trip排序收益不得归因于RL。

## 可靠性、时间与资源

每个候选保存完整解、来源、评分、超cap/不可行/重复/缺失/超时及accepted记录。加载、构造、生成、验证、重启、推理、后处理及失败开销计入总墙钟。进程启动在父进程启动时计时，开始时间跨进程传入；输出完整见证及ready状态须在预算内。大量审计侧录可在解交付后落盘，但侧录组装/候选复制的计算计入算法时间；分开记录输出ready和审计I/O结束。不得将late验证补认按时。所有方法用同一单线程和硬件配置。

预先保持经过验证的共同锚点。方法按时交付锚点为效果0，同时记录无改进/回退；未按时交付完整合规解的槽保留在全部分母并触发可靠性门槛失败，缺失数值不伪造零。作者锚点失败地图仍保留分配分母，分层报告anchor-failure，且阻止完整包通过；不删除不补图。原始不合格候选也保留，不只留最终优解。

本次所有新非RL地图生成、作者锚点、敏感性、校准、控制、验证和分析总上限16 CPU核小时。运行器记录self+children CPU用量、墙钟、完整命令/退出状态和预算预留；不能使用并行墙钟替代CPU累计。最多6单线程工作槽，资源上限预检及失败账在CPU_LEDGER.json；并行仅加速独立任务，不能增加每cell预算。科学调用与合成工程调用分开记账。原30分钟自动任务继续暂停。

## 统计与验收

地图是唯一主推断单位。作者比较逐图效应 `100*(MTC_J1b-MTC_method)/MTC_J1b`；同目标非RL比较使用对应非RL的MTC作分母。报告等权mean/median、全部配对效应、地图bootstrap CI、win/tie/loss、完整可行/按时/回退率、成本差及分家族结果；不把targets、trips、训练seed或求解重复当地图复本。

5%是明确采纳的MTC对作者锚点平均实用目标，6s和12s各须达到，且地图95%CI下界>0。RL对最强同目标非RL还须在两预算实际超过，原路线研究的0.3%平均实用门槛仍保留，CI下界>0、正赢图多于负输图、100%完整独立可行与逐图成本合规。不能看结果降低门槛。

G4主比较族至少为RL对作者、RL对最强非RL各自6s/12s四项；如对更多强基线逐项声称优越，则全部纳入比较族。训练seed预先等权聚合，不选最幸运seed。预定地图bootstrap10000次，seed=20261103，报告未校正95%描述性CI及Bonferroni同时区间（四主比较98.75%，对更多对照按实际预登记族数调整）；门槛按同时下限>0。当前非RL机会报告仅描述，不是RL确认性推断。正式测试样本量须依据开发变异和预期效应在全冻结后计算；旧图或本48图不能充作Formal。

G2通过须有完整冻结数据和作者锚点可靠性；可实现MTC机会按预定效果报告。G3通过须完整强控制和可靠性、剩余机会诊断，不能把非RL收益说成RL效果。G0须存在有先例特定增量且可推翻的物理路线机制；G4训练依G0/G2/G3及其资源包准入。G5全冻结新Formal、G6创新消融与独立复核、G7正文、G8研究包及投稿就绪逐门推进。指标、工程和非RL阳性均不替代RL实证，研究结果允许为阴性。
