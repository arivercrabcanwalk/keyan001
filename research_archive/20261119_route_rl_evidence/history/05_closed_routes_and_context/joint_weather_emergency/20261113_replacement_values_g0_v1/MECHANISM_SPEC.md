# 全部强制站schedule值的共享计算：运行前规格

范围为固定风A、简单能耗、直接TARGET/RETURN轨迹的有限工程。原科学STATE、旧DEV和额度不动；新手写输入不计科研人口。当前未满足G0/G3，不启动训练或Formal。这里的原版是本包新写的强工程参照，不是Liu作者源码。

1. **对象与可证伪主张。** 每站永久同风完整anchor，加K个独立物理schedule副本P；每个副本x有独立同策略同站替换y。求所有强制值T_i(y)，继而求V_xy=F(P-x+y)=min(F(P-x),T_i(y))。失败副本保留ID和站索引，失败y令T=∞。输入非负有限两slot完整返站duty；原cost按站slot逐项浮点累加。组合器/LOO/集合分解不称创新。
2. **新增计算步骤。** 合并原候选和替换候选的makespan事件。本站原eligible最低资源f_i、eligible提案资源小堆；全局仅放各站提案堆首的键w_y-f_i及版本。固定H下无缺站时，T可行当w_y-f_i <= B-Σf；恰缺一站时只激活该站、其f视0；缺两站时不激活。全部同H事件先处理。解决提案后弹本站堆首并推下一个；原f变化同步更新该站版本。不把删除扫描起点H0沿用于可能改善的T。
3. **正确性和复杂度。** 固定H下同站最小w的未解提案有最小需求，故全局最小键不满足slack时所有未解提案均不满足；满足时可安全确定该提案首次可行H。旧版本只失效不能阻挡新堆首。原f只降低、缺站数只下降，资格重建至多两次（另有初始空状态）。每个原事件/提案到达常数次堆更新，每提案解决一次，排序与堆操作O((L+J)log(L+J))、空间O(L+J+n)，这里把整数算术视单位；整数位数/浮点保护费用实测并计入。事件排序、版本、缺站规则是本包具体实现增量；尚无独立新颖性认证。
4. **字面浮点证明。** 复用冻结删除kernel的统一舍入误差界，计算界时把所有有效y纳入本站slot最大duty。原cost与精确加权总和的差≤E。对原比较逐binary64位序取得最大接受cost B；使用B-fixed±E做乐观/保守两次扫描。两个T相等（包括都∞）才认证；否则逐查询原字面二分。overflow和域外直接回原求解器，不放宽1e-7 cap，不重结合((p+d0)+d1)。字面基线共享original-prefix/eligible集合、同累计duty的suffix缓存、重复查询签名缓存；它在固定H下的贪心由浮点加法对非负输入的单调性保证。
5. **学习、对照与费用。** 条件于O=P-x，x/y独立同θ，.5 Σ[V_xy-F(P)](score(x)-score(y))是标准两样本LOORF/PoD，直接对应E[-F(P)]梯度；共享θ不改变独立score零均值论证。ARMS式(4)已有同式，COMA式(4)已有固定其他动作的条件baseline。部署仍输出P的组合，不偷偷并入Y。额外y生成/评分/score计入。等2倍轨迹预算的两个独立删除梯度、两个最优全局常数梯度、整batch两样本PoD全部保留。常数取得依赖有限表，取得成本未计，因此只作oracle诊断。
6. **通过/关闭。** 全部强制值/替换值与强字面基线相同；小例完整穷举和原scorer完整见证通过；有限概率两组全部有理数均值误差0且梯度非零。记录每档/完整耗时，不在暴露输入调K/规模/概率或重复成功计时。variance×完整物理生成评分代理费用未胜强对照就关闭该效率主张；任何新颖性或训练优势只能另凭证据，工程通过不抬G0/G3。
