# 联合费用—返航价值更新：六项 G0 筛选

对象 `JOINT_BUDGET_RETURN_VALUE_UPDATE_V1`。这是查新终局，不是已冻结的新训练方法。裁决：`CLOSE_GENERIC_JOINT_VALUE_UPDATE_NO_DISTINCT_OPERATION`。

1. **输入、输出与原目标。** 固定站点、站型、目标归属、公开恒定风和简单能耗；状态 x 记录未服务目标、各 slot 位置、逐趟电池、开放航次进度、累计 duty、已发生完整费用及剩余 cap。固定部署费用原样计入，不能按“被路线实际启用的机体”重新定义。动作仅 `(slot,target)/(slot,RETURN)`。完整解必须恰好一次服务、全部返航、逐趟电池及累计 duty 合规，完整成本 C≤B（原绝对容差 1e-7），目标为更小 M_return。原坐标独立验收、6s/12s 真实退出和全部开销继续有效。

2. **数学对象与拟议更新。** 给定同一个明确的后续物理策略 π，定义 `ηπ(x,a)=Lawπ(C_final,M_return_final,valid | x,a)`。这里 valid 也记录完整失败，不把超 cap／不完整轨迹删除后再声称它是无条件 law。终局标签由完整独立 scorer 给出。只含 (C,M) 的 law 本身不能区分具有同值的完整合规／不完整轨迹。若用绝对终局量，非终局样本 target 就是后继在同一 π 下的终局 law；若改用累积量增量，则需相应 pushforward 和完整状态。两种写法是普通有限时域 Bellman 适配，不是新步骤。

```text
输入 x,a 与明确的后续策略 π；执行物理后继 x'
若终局：取完整验证标签 (C,M,valid)
否则：从同一 π 在 x' 的联合终局价值构造 target
按既定粒子 MMD／categorical 投影拟合联合 target
部署仅据估计值排序合法 TARGET/RETURN
交付前仍验证完整路线；没有已验证完整解就保留交付失败
```

上述伪码尚无本项目新增的非直接操作。若 child 的策略／剩余预算／mask 与 target 的策略不同，应标明 off-policy 或控制 target，不能继续套固定 π 的评价定理。内部剩余物理预算可由完整费用递推；BMDP 的额外自由输出 β_a 不自动成为本项目部署动作。

3. **最近先例与区别。** Carrara 等 BMDP Eq(1),(2),(4),(11)–(12)、Algorithm2–3 已有预算扩状态、收益／费用双值、拟合 Q、约束动作混合；但它约束期望费用，不是本项目逐条交付 hard cap。Wiltzer 等 MVDRL Eq(1),(3),(5),(7),(10),(13) 已有联合回报 law、joint particle MMD target、BootProj、非负 categorical QP 和 signed TD；Appendix F 已有神经网络拟合联合分布。换成终局成本／返航时间、加预算条件或另放一个 head，没有新增更新操作。物理适配缺口是真实缺口，不能据此宣称算法新颖性。

4. **可证伪预测与当前证据。** 若所提更新逐项仍是 vector Q 拟合、固定策略 distributional Bellman、既有 MMD／QP 投影或状态扩充，则其独立机制主张关闭。本轮已经从原文与固定作者源码命中该条件，不再用另一个两动作 toy 验证平均费用不等于逐样本费用。BMDP Theorem2 明确其最优算子一般不收缩；MVDRL 的固定策略折扣收敛也不证明我们的有限 γ=1 控制收敛。它们没有证明本项目无效，更没有给出本项目优势。

5. **最强同信息、同总预算替代。** 标准 budget-conditioned Q、联合 distributional 监督／TD、BC、无学习和共享相同后继信息的完整路线控制必须可用。强 min-max ALNS 保留原生域、非瓶颈降成本融资、合法多趟修复；忠实风适配作者、已完成 station-bank 精确控制和完整进程交付接口继续复用。候选生成、模型加载、完整验证和后处理均计入 6s/12s。未将这些标准组件跑成新科研批次，未弱化基线。

6. **关闭条件、适用边界与准入。** 关闭的是当前通用联合价值更新作为独立新贡献的切入；没有关闭所有价值学习、近似 critic 或路线 RL。没有证明所有 hard-cap 控制都需要精确 law、精确 h 或全局收敛定理；这些不是原合同追加门槛。一个有明确新操作的近似方法仍可按原 G0/G3、公平完整交付质量验收。当前 G0/G3 未过，不训练／Formal；没有新 checkpoint、科学地图或质量评价。
