# 完整后缀概率引导：六项 G0 筛选与限定终局

1. **输入／输出。** 物理状态 x 含固定站点／站型／target-station、未服务目标、各 slot 位置、电池、累计 duty 和已发生费用；动作仅 `(slot,target)/(slot,RETURN)`。另给完整原成本上限 B、公开固定风与候选 makespan 阈值 τ。基础路线策略为 πθ。拟议引导器计算完整后缀能满足全部物理约束、全图 cap 与 τ 的概率；输出下一物理动作，不选择算法、搜索算子或计算预算。隐变量／应急未来不进入当前对象。部署最终仍须完整解、独立验收、实际退出及 6s/12s 全开销；本轮无策略实现或运行。

2. **数学对象／伪码。** 令 F(B,τ) 为完成恰好一次服务、全部返航、逐趟电池、累计 duty、完整成本和 M_return 阈值的终局事件。标准递推为 `hθ(x)=Σ_a πθ(a|x) hθ(T(x,a))`，终局 `hθ=1_F`，条件动作 `πθ(a|x,F)=πθ(a|x)hθ(T(x,a))/hθ(x)`。若编译的是替代概率模型 q，则相同递推给的是 h_q，不自动等于 h_θ。

```text
输入：当前物理前缀，πθ，B，τ，已定义的可计算概率模型 q
为 q 的充分状态与物理约束状态建立积状态
对终局记成功=1，失败=0；对非终局按 q 的动作权重做 sum-product 递推
用 h_q(child) 引导 πθ 的下一 TARGET/RETURN
完整终局由原坐标 scorer / cap / duty / energy 独立验收
```

该伪码没有本项目新增的非直接步骤。若 q=πθ，必须证明聚合状态对策略后缀分布充分并计入完整编译成本；若 q 是压缩／蒸馏模型，则保持“近似引导”的身份，不称原 actor 的精确条件采样。神经网络拟合 h 或给 h 加特征本身也不是本轮的新步骤。
