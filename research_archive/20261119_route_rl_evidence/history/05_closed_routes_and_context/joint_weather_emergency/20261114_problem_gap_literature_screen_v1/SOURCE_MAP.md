## Search and reliability notes

- Search was targeted to fixed/steady wind, multi-trip drone routing, fleet makespan, energy constraints/cost caps, and route-selection RL.
- OpenAlex fallback script returned HTTP 429; web search and the above primary/institutional sources were used afterward.
- GitHub repositories were inspected as implementation leads, not treated as literature proof.
- The source set is sufficient to reject broad novelty claims about wind-aware RL routing, multi-UAV wind planning, or multi-trip energy-constrained drone routing individually. It is insufficient to certify novelty of the exact conjunction; that needs a formal database search and a source-level crosswalk against LRPHSD.
