# 可行见证约束下的区间反事实梯度：运行前六项规格

本包接续已失败的全动作精确完成表，检验一个不同的组合操作。固定风A、原物理参数、完整成本cap、最终返站M保持；仅root，所有数值计算只在<REMOVED_ENDPOINT>。此处是固定策略的有限工程反证，不是训练、科学地图、作者锚点或G0/G3通过声明。

## 1. 输入、状态与动作

输入是4个预先手写的全新3/4/4/5目标二维fixture、固定背景站、两种无人机电池、两套预先指定的四维线性softmax参数。初始完整可行路线W给出工程cap=C(W)；它不是作者Rw，科学A合同不变。

扩展状态x=(物理前缀,W)。W必须逐slot保留全部已完成航次和当前航次的已服务前缀。actor输出仍是(slot,target)或(slot,RETURN)。本包为静态路线构造序列，不声称是实时空闲机调度器。

## 2. 真正执行的组合操作

对TARGET，确定性地从W的未执行部分删除该目标，把它插入所选slot当前前缀之后，其余目标相对次序不变；对RETURN，将当前航次在真实前缀处截断，剩余后缀从站点另起一趟。没有调用ALNS、DP、beam或模型选择器。

只保留完整电池/覆盖/归属/累计duty合法、C(W_a)<=cap+1e-7且M(W_a)<=M(W)的动作，随后携带W_a。无目标的空RETURN被禁止。执行W当前首动作总有一个可行延续，每个TARGET减少未服务数，每个RETURN消耗至少一个尚未闭合的TARGET，故至多2n步终止。不同slot的序列化顺序不改其物理并行累计duty。

该支持约束可能删去先变差后变好的路线，所有对照共用它；强ALNS未来仍保留原生域。它本身是见证/备用规划与单目标移位的常规组合，不独立宣称新颖性。

## 3. 对实际策略成立的区间

最小化问题中，一个可行W_a只给Q*(x,a)上界；没有递归约束时不保证Qπ，更不保证每条随机续接G。这里由见证上界不增和有限终止归纳得到每条允许续接G<=U_a=M(W_a)。

L(x)取以下有效放松下界的最大值：已固定背景M；各slot已执行duty加直接返站；两slot上述和加未服务service后的二分之一；每个未服务目标在两个slot中最早直接到达、服务并返站的较小值。固定风有向飞行时间满足三角不等式。动作后用L(x_a)，并以min(L,U)吸收binary64的上舍误差；只在L==U逐字相等时跳过随机尾部，容差不能变成主动缩窄区间。

令h_a=(L_a+U_a)/2，z_a=∇logπ(a|x)，c=Σπ_a z_a h_a。对于独立反事实A~r，执行A后继续同一个π，有

`g_hat(x)=c+(π_A/r_A) z_A (G_A-h_A)`。

π、h、r和支持在本次估计中固定；h/r停止梯度。r=0.1π+0.9r_width，r_width∝π||z||(U-L)，全零时不用探测而直接算c。它最小化的是残差二阶矩的区间上界（无defensive混合的理想式），不是实际方差的全局最优分布。

**新增待检验操作**是把递归完整路线证书用于实际策略的残差区间，再将其用于按动作分配独立续接探测和零宽尾部消除。它不同于用Q*上界直接监督actor；但CV/IS/备用规划已有先例，组合是否有独立研究价值仍待结果与进一步查新。

## 4. 状态分布与验证

主轨迹始终按π生成。每个访问状态另抽独立探测动作与π尾部，梯度求和；探测不会改变主轨迹的状态分布。不能把每步改为r后仅乘局部π/r。固定θ的完整期望、返回二阶矩和梯度方差在有限状态DAG上精确递推（binary64算术），不依赖随机试验挑结果。

检查：所有可达终局与独立冻结wind_scorer核对；每个状态的所有后继终局范围落在[L,U]；候选与真实∇J、中心差分一致；普通CV纠偏与状态baseline期望一致；另外保留一个Q*/Qπ上界反例及一个局部IS错误的状态占用反例。原有固定风变换和旧fixture不重跑。
