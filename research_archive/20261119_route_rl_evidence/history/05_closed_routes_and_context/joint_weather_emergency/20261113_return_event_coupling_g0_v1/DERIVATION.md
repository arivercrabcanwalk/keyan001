# 边际、局部信用与适用边界

固定物理前缀s；根π(a|s)有独立可微logit，后续策略在本工程中固定。令Q_a=E[Y|s,a]，J=Σπ_a Q_a，则根梯度第a维为π_a(Q_a−J)。A/B iid于π，给定(A,B)的续接可以任意耦合，只要各自边际仍是原策略；因此E[0.5(Y_A−Y_B)(e_A−e_B)]=∇J。相同根动作时e_A−e_B=0，可直接省掉这对续接；所有控制都用相同捷径。这个结论不需要两条续接独立，也不允许把根动作改为相关后继续使用同式。

每个单站物理状态至多两条非空开放trip。RETURN关闭一条trip，使对应slot处于home，当前无任务时再次RETURN非法；在下一TARGET之前每slot最多RETURN一次。所以RETURN-only前缀最多五条（零条、两个单条、两个双条次序）。闭包枚举每条路径的策略概率乘积，并保留到下一TARGET/终局/死端的全部质量。不同RETURN次序若到达完全相同的充分状态可求和，恢复微动作trace时仍须按条件路径概率抽样。不能只保留target-ID而丢弃新电池/duty/slot状态。

定义P_s(u)为下一服务事件的完整结局核。对粗标签c=target-ID（终局/失败有独立标签），p_s(c)=Σ_{u:c(u)=c}P_s(u)。先按任意具有p_s和p_t边际的粗耦合抽(c,d)，再按条件核耦合u/v，乘法展开后分别得到P_s和P_t。最大耦合可提高同target概率，但不保证终局费用相关性或方差更好。使用flat宏事件最大耦合为同组件强控制，不能把全部收益归因于分层设计。

按绝对已服务目标数追平只调度两个模拟器的计算。推进的一侧始终使用自己的完整下一服务核；暂停侧不改变状态。完成追平后继续用保边际的事件核，故每侧完整物理路径的边际策略律不变。若一侧终局，则独立推进另一侧。RETURN的真实飞行时间/能耗和累计duty已经写入各自状态；内部计算暂停不是实际WAIT，不允许改变物理时钟或输出动作。

工程actor为显式Markov策略，状态包含完整已闭合trip、当前trip/位置、电池、累计duty、剩余目标、公开风及站型；没有隐藏RNN、dropout或last-action记忆。若换成有隐藏历史的actor，必须把该记忆纳入闭包状态；不能按仅物理状态错误合并。训练使用完整终局指标、无discount/按动作步数处罚；改变这些条件须把路径累计奖励/折扣也纳入核。

精确配对二阶矩由有限双树递推得到，不用64采样估计方差。局部g在A≠B时平方范数为0.5(Y_A−Y_B)^2；trace variance=E||g||²−||E g||²。它只审查根logit信用；共享网络参数的Jacobian、其他状态占用、训练动态和实际神经forward费用尚未测量，不以此认定全算法效率或RL优势。
