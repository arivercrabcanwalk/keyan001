# 失败反思：信用估计之前需要可改变的新路线

本轮确实实现并检验了新的联合续接核；它不只是改文件名或缓存。但正确的联合核不创造原策略支持之外的路线，也不能在恒定终局上产生有意义的梯度。

真实旧表的后登记描述（runs/POSTHOC_COVERAGE/RESULTS.json）表明，给定本批prefix后：mixed_reset_2d完整状态24、接受1；sd_tight_reset_2d完整状态12、接受2；binding_cost_2d完整状态23、接受1。三者公共重排后、尚未筛成本/H的最小M分别为15.573337934714694、14.994304087588706、16.242756537337915，恰等于各自锚点；全部终局Y跨度0，改善状态0。这个表分析没有新scorer/solver/样本，CPU0.008997218000000001s。

单SD控制有6个完整状态，4个接受且改善M；Y跨度1.3241059689285706，根局部梯度非零。其两设置候选方差与强控制相同，额外闭包/分层操作增加费用。这反驳当前工程效率主张，不代表双机有信息的情形已经被测过。

三个双机输入的设计错误是没有先保证待估计的局部决策仍能改变强公共后处理后的完整目标。两个已放入不同slot开放trip的目标，之后的TARGET/RETURN续接不能把它们合并进同一trip；公共整趟重排只改变trip所属slot，也不能合并。几个不同的动作和真实不同的raw路线因此仍可能对应同一交付值。这个原因与“转移确定所以所有RL方差/价值为零”的旧错误论断不同，后者不成立。

下一对象为**目标同趟关系的生成**，不是进一步给局部梯度换控制变量。下一份候选必须回答：在空前缀构造时，哪一个步骤实际改变目标分组、顺序或分趟？它怎样在两个不同电池和共同H下决定下一TARGET/RETURN？完整路线后果怎样更新该步骤？哪一个控制加入同组件后会推翻其预期收益？目前尚无已准入的新生成机制，不伪造G0通过。

不因nonRL能表示同一路线就否定RL；同新物理解、公共组件及全生成费用交给nonRL/BC/标准RL作强控制。不能把省掉一次forward、组合器收益、有限边际正确性或小SD例的物理headroom归为RL路线胜出。未来工程不再用本批已暴露四例选择超参数或重跑成功计时。
