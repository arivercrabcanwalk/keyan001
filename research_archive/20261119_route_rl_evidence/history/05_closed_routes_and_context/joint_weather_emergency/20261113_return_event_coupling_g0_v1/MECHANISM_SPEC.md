# RETURN后按目标服务对齐的续接耦合：六项候选规格

候选RETURN_EVENT_ALIGNED_CONTINUATION_COUPLING_V1。本包准许一个有界机制工程见证；尚未通过科学G0/G3，不训练。标准模块可以组成实质算法，本包不声称发明新的通用梯度原理。

1. **输入/输出。** 固定风、简单能耗、固定站型/归属、公开物理前缀。动作始终为(slot,target)/(slot,RETURN)。仅研究站内LD/SD多趟生成的一次局部信用；后续完整算法仍须共同H的独立生成强控制、完整作者同风cap与6/12s交付。本工程使用四个全新手写几何及合法手写锚点，绝非作者Rw或新科学地图。

2. **具体新增运算。** 在同一物理前缀，根动作A/B独立取自同一策略。原强控制按每个微动作做最大耦合；候选先精确展开至下一个TARGET之前的RETURN-only闭包。两slot最多各RETURN一次，所以只有空串、单RETURN及双RETURN的两个次序，最多五个RETURN路径；每条均保留概率和可恢复物理动作。两分支先按已经服务目标数追平，再对下一target-ID边际做最大耦合，其内再耦合slot/RETURN集合。某分支推进时另一分支只是在模拟器内暂存，不新增WAIT。该分层改变完整续接的联合律，保持每条分支自己的微动作策略律；不是共享前缀缓存，也不是将RETURN无费用删除。

3. **参数更新。** 根动作独立时，局部向量估计为g=0.5*(Y_A-Y_B)*(onehot(A)-onehot(B))。续接只改变Y_A/Y_B的相关性，不对耦合采样路径直接求导；两分支边际各为原续接策略，故期望仍为根logit梯度。完整共享网络更新还须正确抽取占用状态及各状态贡献；本包没有用根局部验证冒称全网络梯度/训练。非独立根动作直接套LOO会偏，明确禁止。终局Y为公共typed整趟重排后原scorer验收的M；物理/cap/H失败用已验证完整锚点的M，失败原记录保留。

4. **先例与候选差别。** MVD的差分期望/协方差、Dong等耦合离散梯度、Mohri概率闭包和Anderson事件通道共享均为已有方法，不单独称新。这里待验的组合是两slot有限RETURN闭包＋按绝对服务数追平＋先耦合target再耦合返航/slot的层次核。它与每步动作最大耦合、同闭包的完整宏事件最大耦合都可产生不同联合律。没有声称有限查新排除了所有已有同构方法；若仅复现现成的同一组合，独立新颖性关闭。旧MACSIM完整交错与旧删除/替换估计实验直接复用，不重跑。

5. **可证伪预测与强控制。** 四新工程输入×两固定续接设置，对比iid、微动作最大耦合、同闭包同服务对齐的flat事件最大耦合、候选target分层耦合。全部共享原物理mask、完整scorer、精确typed重排、固定锚点、缓存规则与根动作分布。精确枚举验证边际、局部均值和二阶矩；64配对采样只测运行费用/操作数，不从MC噪声选择效果。核心效率是假说：候选的trace-variance×完整配对运行费用优于已列最强控制；同时报告variance×策略求值次数。小策略求值不是神经forward，不能外推训练或6/12s性能。

6. **停止规则。** 正确性失败即停止，保留一次代码修复额度且不改输入/设置；成功计时不重复。八个case-setting至少六个须有非零根梯度；候选相对每行所列最强控制，variance×策略求值和variance×配对墙钟两个量的几何均值比均须<1，且两量各至少75%有效行获胜。这个有限工程条件并非科学统计显著性。未满足即关闭当前效率主张，不追加fixture/权重/采样来挑阳性。工程阳性最多支持继续G0候选审查，不提升科学G3、不启动训练/Formal。强ALNS、公共bank及成本中性重排始终保留，未在此工程假装比较ALNS质量。
