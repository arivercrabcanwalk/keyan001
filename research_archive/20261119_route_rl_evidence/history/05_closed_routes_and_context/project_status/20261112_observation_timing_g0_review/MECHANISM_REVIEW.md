# 一个候选的完整 G0 审查

候选命题：只输出 TARGET/RETURN，利用路线导致的后续观测时机变化来选择下一物理动作。裁决 `G0_NO_GO_OBSERVATION_TIMING_STANDARD_POSMDP`，关闭该候选的创新准入。本文件给出可判定对象，不把已有框架重命名为新机制。

**输入和输出。** 输入为固定站点、站型、任务到站归属、机型/电池/累计 duty、严格逐图作者成本锚点、已知任务，以及公共历史 `H_n`。在动态讨论中，`H_n` 还须包含按时间与固定 tie-break 排列的观察、已派遣承诺、完成/失败、预报发布版本、reservation、尚待执行的同刻 slot；隐服务阶段与未公开天气/故障仅属于条件模型。候选、RL 和全部 non-RL 共享同一个前缀与冻结模型。输出只为一个 `(slot,target)` 或 `(slot,RETURN)`；slot 必须是当前合法决策 slot。没有合法动作时如何由环境推进须显式定义，不能用 RETURN 或内部等待偷加 WAIT。

**数学对象。** 若考虑动态模型，令 `X_n` 包括车队物理状态、隐天气/故障过程与事件阶段；时间、已产生成本和 makespan 账本也进入状态。公共前缀诱导 `b_n(dx)=P(X_n∈dx|H_n)`。给定当前合法动作 `a`，模型产生到下一个车队决策前沿的联合核：

\[
K_a(dx',d\tau,do\mid b_n,H_n).
\]

`tau` 是下一次政策回调的间隔，受所有 pending 事件和同刻闭包次序影响；它可以为零（同刻另一 slot 的回调）。固定公共状态后，未知的持续时间和观察共同更新信念。对密度存在的情形，可写为自行推导的条件化形式：

\[
b_{n+1}(x')=\frac{\int b_n(x)k(x',\tau,o\mid x,a,H_n)\,dx}
{\iint b_n(x)k(z,\tau,o\mid x,a,H_n)\,dx\,dz}.
\]

混合离散/连续持续时间应使用同一支配测度的质量/密度或正规条件分布；零似然、粒子退化和相容隐阶段都须有冻结规则。将未知阶段直接设为保守上界不是这个后验。该对象是普通部分可观测半马尔可夫决策的历史条件化表达；保留同刻队列可避免把零时间回调硬塞进只支持正持续时间的实现。

完整路线对象仍为 `R`。静态可接受集为

\[
\mathcal F=\{<WINDOWS_PATH> C(R)\le C(R_{Liu})+10^{-7}\},\qquad
\min_{R\in\mathcal F}M_{return}(R).
\]

这不是期望成本、机会约束或跨图均值成本。若把它移到随机在线世界，逐场景作者锚点、已承诺前缀和最终可行性还须独立定义；目前不存在“把终局违约交给惩罚即可满足原 cap”的证明。前述 `K_a` 在本地尚未实现为公共因果分叉；静态构造器则没有这项未知外生过程。

Chronos 的原稿在 pp.4–9 将 `Q(τ,...)` 定义为 CDF，却在精确持续时间条件化中沿用同一符号，p.14 推导又写 density `f`。本次图像确认了这个记号差异；没有查作者代码，保留为复现歧义，不宣布作者实现错误。连续精确观测的条件化与区间/删失事件使用的 CDF 不应混用。POMCP p.4 的精确观察匹配也不是现有连续风/时间向量的现成粒子过滤器。

本轮另取得 SPARROW 的 [arXiv 标识页](https://arxiv.org/abs/2609.21008)，只登记摘要级导航/POMCP线索；未读其全文，不把它作为本裁决必需的证据。三篇新 PDF 都只作指定方法段阅读，不声称整篇结果或 SI 已完成审计。

**可证伪预测与信息归因。** 假说要求：在同一合法物理动作与随后相同的物理模型下，只改变未来观察可用性就可能改变后续动作排序；但效果尚未检验。固定一个候选动作、共同后续可行策略集和损失函数时，信息价值可用下式表达：

\[
\underbrace{\min_u E[L(X,u)\mid H,a]}_{\text{不使用新观察}}
-\underbrace{E_Z[\min_u E[L(X,u)\mid H,a,Z]]}_{\text{使用新观察}}\ge0.
\]

不等式来自允许条件策略忽略 `Z`，而不是本项目数值结果。它没有说“走短任务必更好”或“RL 必胜”：改变 TARGET 还会改变已服务任务、剩余电量、可用时间和终局可行集，不能把两个物理路线的全部差值叫信息收益。若公共发布日程独立固定且所有方法都能及时读取，单纯增加位置传感的解释消失；历史持续时间提供的信息仍需单列。若隐风/未来任务完全已知，则不再存在其额外学习价值，但路线排序价值仍可能存在。

**同信息、同候选、同墙钟强控制。** 沿用前包 G3 控制清单，增加明确的 history-based non-RL causal rollout / belief-tree 适配资格。它与 RL 使用相同公共前缀、后验模型、物理候选、全图截止时间、失败和回退规则；所有前缀重建、过滤、采样、候选生成、搜索、模型加载和验证计入 6s/12s。时间后验使用/忽略与规则/BC/RL 是不同因素，必须在相同物理环境和搜索深度下比较。观察屏蔽仅可作为另冻的归因干预，不能作为主比较中故意削弱 non-RL 的方式。共享信息优于缺信息规则不支持 RL 独立增益。

当前没有实现、候选质量或墙钟证据来确认哪个 non-RL 最强。oldbeam 历史结果和其余强控制均保留；POMCP 的一般表达能力也不等于已经在当前连续模型和 6s/12s 内通过 G3。BC initial 与 RL 更新后模型分开评价，至少三独立训练 seed 的 G4 只在 G0/G3 都通过后进行。

**关闭条件及本次判定。** 以下任一成立就不以本候选准入训练：规则仍为标准后验/rollout 的变量替换；须新增局部风传感、WAIT、改降或放宽 cap 才存在；仅有调度器回调频率差异；没有同合同物理见证与强 non-RL 资格。本次第一项已成立，静态接口也没有该未知外生观测输入，故关闭此创新候选。此结论不证明所有动态信息策略无用、不关闭整个天气研究，也不产生新科学负结果。G0/G3/G4 保持未通过。
