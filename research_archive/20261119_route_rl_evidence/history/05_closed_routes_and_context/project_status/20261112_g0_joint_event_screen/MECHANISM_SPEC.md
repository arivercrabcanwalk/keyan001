## 1. 完整输入与物理输出

输入是公共历史 H_t：当前时刻，全部公开站点/站型、无人机所属站与机型、可用状态、位置、本趟能量、累计 duty，已释放任务及其站归属/服务/能量/priority/deadline，已公开完成/失败记录，实际已发布的风观测和预报更新历史。历史只来自共同 ledger，不读取 simulator 的私有事件队列、未释放任务、真实未来风或内部提前排定的到达时刻。

学习或规划用的随机模型 P_TRAIN(ω|H_t) 在独立 TRAIN 上拟合并冻结。ω 是未来风、公开预报更新、请求集合及释放时刻的联合流，允许共用潜在风暴路径；它不是部署时真实未来流。所有对照共享同一模型、同一历史与可用预测状态。若某项信息只能由 RL 获取，该比较不成立。

物理输出严格为 a=(slot,target) 或 a=(slot,RETURN)。站点部署、站型、目标到站归属、机体归属站、异构能力和累计 duty 沿用当前协议。环境产生公共可行候选 A(H_t)，无候选时记录显式终止失败；失败状态不是新策略动作。该候选不加入 WAIT、改降、跨站归属、搜索算子或预算选择。

## 2. 数学对象与因果续接

固定一条仅使用公开历史的续接策略 μ。对共同随机样本 ω，先执行候选物理动作 a，再由 μ 在每次公开事件后行动；未来请求只在其 release 时刻公开。记录完整 episode 的向量：

\[
Z^\mu(H_t,a,\omega)=(H_{map},\ CVaR^{task}_{90},\ C,\ M_{return},\ complete,\ failures).
\]

H_map 的分母是该地图最终出现的全部高优先级任务，不是已服务子集；先逐地图求比例，再对地图平均。CVaR90 是该地图任务迟到的最差 10% 均值，沿用原协议对未服务任务的处理，不偷换为“跨天气场景 CVaR”。C 与 M_return 来自原独立完整解 scorer。任何部分、超时、未服务或回放失败分别保留。

待研究对象是向量分布及其期望：

\[
\mathcal L^\mu_{joint}(H_t,a)
=\operatorname{Law}_{\omega\sim P_{TRAIN}(\cdot|H_t)} Z^\mu(H_t,a,\omega),
\quad Q^\mu_{joint}=\mathbb E[Z^\mu].
\]

有限场景近似使用相同的真实因果续接 μ：

\[
\widehat Q^\mu_{joint}(H_t,a)=K^{-1}\sum_{k=1}^K Z^\mu(H_t,a,\omega_k).
\]

对同状态不同动作可用 common random numbers，降低成对差方差。若每个场景提前获知全部未来并重新求最优完整路线，得到的是 perfect-information 松弛/oracle，不是上述可部署策略的 Q，也不是合法 rollout 专家。μ、抽样器、候选生成、预算截止与独立完整回放必须一致，才可将不同估计器的效果归因。

神经 Q 可以通过 Monte-Carlo 回归、TD 或策略迭代估计该量；这些均是标准方法。此次没有确定一种区别于已有方法的新估计器，因此没有完成可准入的新算法。

## 3. 解析反例：边际概率和任务总数相同，动作排序反转

在同一所属站的一个未来决策前沿，有两架可用无人机 A、B。B 能在期限内单独服务位置 1、2、3 中的任意一个，但无法在期限内连续服务两个。A 的当前合法动作是访问已公开例行目标 L 或 R；完成后，它分别只能及时服务未来请求 1 或 2。未来请求 4 对两机均不能准时，但可以迟到服务；所有任务最终完整交付与完整原成本仍须另行核验，本例不声称已满足它们。

这些可达关系有简单几何见证：令未来位置 1=(-l,0)、2=(l,0)、3=(0,l)、4=(0,10l)，B 在原点，A 在执行 L/R 后位于位置 1/2。取共同速度 v，剩余时限 δ 满足 l/v<δ<sqrt(2)l/v，且服务时间取足够小的正数。B 可及时到达 1/2/3；A 从任一端到其他近点至少 sqrt(2)l；B 先访问一个点后也来不及访问第二个。足够长的后续 horizon 可用于迟到交付，但本例没有求完整路线、Liu 锚点或成本 cap 证明。

两个条件联合分布分别是：

\[
P:\ \{1,3\}\ (1/2),\quad \{2,4\}\ (1/2);
\qquad
Q:\ \{2,3\}\ (1/2),\quad \{1,4\}\ (1/2).
\]

每个位置在两分布中的出现概率均为 1/2，每次恰好两个高优先级请求。单请求 union coverage 总期望对 L/R 都是 3/2，因为 B 单独覆盖 1/2/3，位置 4 均不覆盖；它无法区分动作。

|条件分布|请求集合|概率|选择 L 的准时数|选择 R 的准时数|
|---|---|---|---|---|
|P|{1,3}|1/2|2|1|
|P|{2,4}|1/2|1|1|
|Q|{2,3}|1/2|1|2|
|Q|{1,4}|1/2|1|1|

因此在 P 下，逐地图准时率期望为 H_L=3/4、H_R=1/2；在 Q 下为 H_L=1/2、H_R=3/4。分母始终是 2，没有以期望总数代替逐地图分母。最优物理动作确实反转。

结论只涉及表示的信息充分性：一个仅保留各请求边际概率及 R1 的表示无法同时给出两种联合分布下的最优排序。它不是 RL 专属优势。获得完整联合分布的非 RL 场景控制会作出同样的排序。若 P/Q 无法由公共历史区分，任何只使用该历史的方法，包括 RL，都没有识别真实条件的依据；本例没有给 RL 私有的 P/Q 标签。

与历史 MATHEMATICAL_OBJECT.md 中“一机两个同时请求”的过计数反例相比，这里增加了：同边际、同固定请求数、两合法路线选择和最优动作反转。新增的是明确的诊断反例，不是新算法或经验阳性。

## 5. 可证伪预测、强对照和关闭条件

预测 A：若公共历史确实包含可学习的天气—成组故障关系，使用联合条件流的策略在全新冻结数据上相对仅用边际流的同类策略应改变物理动作，并改善原已冻结主指标。若条件分布不可识别、排序无变化或无完整可行增益，则该信息机制关闭。

预测 B：共享完全相同联合流模型的真实 non-RL rollout、联合车队规划和 preparedness 规则必须作为强对照。只有 RL 超过它们，且 BC/监督、initial 或无学习规则解释不了增益，才支持 RL 额外贡献。联合流使所有方法同时改善不等于 RL 起作用。

预测 C：原 WX 目标要求的 spatial-uniform 替换必须独立重训，所有非坐标事件实现配对。另可预先提出“保持边际概率和每批请求数、改变联合配对”的机制检验；它只用于区分相关性与边际强度，不替代原 uniform 验收。任何新消融均须先冻结，再申请相应后续阶段，当前未执行。

主目标边界：当前静态合同仍为逐图 C<=C_Liu+1e-7、同 6s/12s 下改善 M_return；上面的 timeliness 反例只对 WX 历史假说有解释作用，不是静态主目标的机会或成本证明。若未来研究动态紧急流，须先定义因果作者适配与动态成本锚点，不能把预知未来请求的 Liu 完整解交给策略作为共同起点。WX 的 1% 均值成本约束也不替换当前静态 cap。

本候选的关闭条件已经满足：算法主体仍是已有因果 rollout/VFA，没有被证据建立的独立算法增量，且新近 non-RL preparedness 先例尚未全文对照。故本次只交付规格和反例，状态 G0_NO_GO_AS_DISTINCT_ALGORITHM；修复旧 driver 或增加训练种子不解除此裁决。
