## 不能从作者任务直接移植的部分

CFA README 先缩短距离 15% 并删除往返不可达客户，再抽样生成派生实例。ODS 内六方法有大量 `served < m` 行；这些记录在作者任务中的合法性与罚项含义需正文定义。不能把按已服务子集获得的成本当作 Liu 完整服务、同部署、同目标归属、同累计 duty 的完整锚点，也不据服务数较少断言作者算法不可行。

300 个派生 ID 来自 100 个原身份，且每 ID 10 条记录未提供场景配对标识。任何未来统计必须先冻结地图／原身份层次与外生流配对；不能把 18,300 行当作同问题的新独立样本，不能把 Oracle 单记录复制十次制造配对。

ODS 的 Oracle 不具备已取得的完美信息或最优性证明。即使未来确认它是非因果信息界，也只用作参考界；若只是限时启发式，必须照实标注。两者都不自动成为可部署因果强对照。原缺失失败字段保留，不补零。

## 必须共同冻结的比较合同

1. 每图共享完整可行 Liu 锚点。所有候选完整服务，并满足 `C <= C_Liu + 1e-7`、epsilon=0；不能跨图相抵。主目标 M_return，MTC 辅助。失败、超时、不可行均保留分母；回退的时间与收益单列。
2. 信息、mask、初始化、物理候选及候选生成／检验成本共享。动作只为 `(slot,target)` / `(slot,RETURN)`，不加入 WAIT、改降或算子选择；部署／站型／target-station 固定，返航不清累计 duty。
3. 所有方法以同整图 6s/12s 比较；真实 rollout 必须调用共同物理转移和已冻结因果 base policy，不能用随机扰动评分代替。不限预算结果仅解释潜力，不能进入同预算优越性主张。
4. 最强 non-RL 包含登记的最强同目标无学习方法，以及合资格监督／BC 引导规划。无 RL 更新的学习式规划依然属于 non-RL。BC initial 独立保存、独立评价；不能只选弱规则或弱作者 adapter，也不能把 initial 收益记为 RL 增量。
5. 若保留路线增强或其他后处理，必须做对称开关／共享开销和明确归因；RL 对搜索算子不作选择。不能把后处理后的质量全归因于 actor。
6. 每种学习控制的离线训练信息／数据／资源单列，正式推理共同预算；随机重复必须明确地图与 seed 层次。G0/G3 通过后 G4 至少三个独立训练 seed；不得只挑部分 seed 或重用已暴露 DEV 反复调参。
