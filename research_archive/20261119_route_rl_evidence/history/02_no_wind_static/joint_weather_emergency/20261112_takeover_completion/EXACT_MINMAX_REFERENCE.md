## 2. 精确模型（与 scorer.py 逐行对齐）

给定锚点后，`station_types` 与 `target_station` 固定（scorer.py:269-272），每个目标恰好服务一次，问题**按站完全解耦**。

**每站（kind k）**：目标集 `T_s`；一趟 trip 是闭合巡回 `station → perm(B) → station`，其中

    travel   = tour_length / speed                          (speed = 900, problem.py:8)
    duration = travel + Σ_{n∈B} n.service                   (scorer.py:166)
    energy   = travel * flight_energy + Σ_{n∈B} n.energy    (flight_energy = 0.018, scorer.py:167)
    capacity(slot) = large_battery(0) = 1.0 / small_battery(1) = 0.81   (scorer.py:168)
    limit(kind)    = small_duration 480 (kind 1) / large_duration 600 (kind 2)  (scorer.py:184)
    kind 1 → 只有 slot 1；kind 2 → slot 0,1；kind 0 → 无

约束：`energy ≤ capacity + 1e-7`、`slot_duty ≤ limit(kind) + 1e-7`、每个目标 `dist(station, n) ≤ radius(kind) + 1e-7`（scorer.py:153,173,185）。

**站目标**：`makespan_s = max_slot Σ_trips duration`、`operating_s = Σ_trips duration`。

**全局**：`M_return = max_s makespan_s`、`cost = fixed + 0.5·Σ_s operating_s`（fixed 与锚点相同），
`cost ≤ cost_anchor + 1e-7` ⇔ **`Σ_s operating_s ≤ operating_anchor + 2e-7`**（本文件里记作 `cap_op`，逐图数值见 `rows[].cap.operating_cap_min`）。

> 与任务书给定规格的两点细化（都按 scorer 原码，不按直觉）：
> 1. **duty 上限按 kind 而不是按 slot**：scorer.py:184 的 `limit` 在 slot 循环内按 `kind` 取，因此 DABS 的 **slot 1 也是 600**，不是 480。本实现的精确前沿按 600 计算；重构解经 scorer 复核 issues 为空。
> 2. **coverage 半径按 kind**（scorer.py:153）：kind 1 → 4000 m，kind 2 → 5000 m；与 `global_env.py` 的 DABS 双机同半径一致（CODE_MAP §B.1）。

## 3. 精确归约与算法（含证明）

**引理 1（TSP 支配）** 对固定目标集 B，`duration` 与 `energy` 都是 `tour_length` 的严格增函数（斜率 `1/900` 与 `0.018/900`），且服务时间/目标能耗是常数。故 **B 的最短闭合巡回同时最小化 duration 与 energy**；一张 Held-Karp 表（`2^n·n²` 状态）可服务所有 slot。

**引理 2（划分支配）** 固定"哪些目标去哪个 slot"（下称 split），且固定一个 slot 的目标集 U。站的两个目标 `M_s = max_j load_j`、`op_s = Σ_j load_j` 对每个 `load_j` 都单调不减，而 `load_j` 是 U 的划分中各趟 duration 之和。故把 U 换成**总时长最小的划分** `d_j(U)` 不会使任一目标变差；其它划分被支配。

**定理 1（站前沿）** 任一可行站配置 = 一个 split `U ⊆ T_s` ＋ 两侧各自的一个划分；由引理 2 它被 `(d_0(U), d_1(T_s\U))` 支配。于是

    frontier_s = { ( max(d_0(U), d_1(T_s\U)), d_0(U)+d_1(T_s\U) ) : U ⊆ T_s }

（kind 1 只有 U = ∅，退化为 `(d_1(T), d_1(T))`）。枚举全部 `2^n` 个 split 即得**完整** Pareto 前沿；`d_j` 由集合划分 DP 求：

    d_j(∅) = 0
    d_j(M) = min over B ⊆ M with min(M) ∈ B and energy(B) ≤ cap_j + 1e-7 of [ dur(B) + d_j(M\B) ]

复杂度 `Σ_M 2^(|M|-1) = (3^n − 1)/2` 次转移/slot；单站总代价 `O(2^n n² + 3^n + 2^n)`。

**定理 2（全局）** 给定阈值 T，`min Σ_s op_s s.t. ∀s: M_s ≤ T` 等于 `Σ_s f_s(T)`，其中 `f_s(T) = min{ op : (M,op) ∈ frontier_s, M ≤ T }` 是阶梯函数。故

    M* = min { T ∈ 𝒯 : Σ_s f_s(T) ≤ cap_op },   𝒯 = 所有站前沿出现过的 M 值（有限）

按 𝒯 升序扫描，第一个可行 T 即精确最优。**这是精确求解，不是启发式搜索**；并且锚点自身配置一定被枚举到，所以必然可行（6 张精确图实测 6/6 可行，见 §4 第 5 项）。

**枚举规模（实测，可复核 `rows[].station_frontiers[]`）**：6 张精确图共 18 个有目标站，`n ∈ [4,14]`，
合计 **931,355** 次划分-DP 转移、**389,248** 个 Held-Karp 状态、**29,462** 个 split。
最大单站为 5x35_o1 的 station 4（kind 2, n=14）：552,607 转移 + 229,376 HK 状态 + 16,384 split，实测 < 1.4 s。

## 7. 结构性解释：headroom 从哪来、为什么有的图是 0

1. **配平是要花钱的。** 站前沿一律呈"M 越低、operating 越高"：把目标拆成更多更短的趟会让载荷更均衡，但每多一趟就要多付一次往返站点的站边，`operating` 必然上升。前沿斜率就是"买 1 分钟 M 要付多少 operating"。
2. **3x20_o1：cap 阻断（已证）**。st0 从 66.823954 降到 56.818084 需要 op 从 110.903628 升到 111.512930（+0.609302），而 cap 只剩 2e-7 的额度；st2 的 M 最高只到 64.209711。因此 `M* = 66.823954 = anchor`，**不是搜索不到，而是任何方法都不允许**（在 `cost ≤ anchor.cost + 1e-7` 内）。
3. **4x25_o1：结构性下界**。st1 是 kind 1（**单 slot**），`makespan = 该站总时长 = 120.941553`，前沿只有 1 个点（即"最小总时长"本身），锚点已达到；与 cap 无关。任何方法都无法把该站 M 降到 120.941553 以下。
4. **3x15_o1：免费午餐**。13.34% 的改善完全来自换 slot 归属（`operating` 一点没变：exact op ≡ anchor op ≡ 199.873108163），这也是 LPT 能 0 成本拿到的原因。
5. **3x10_o1 / 5x35_o1：锚点被严格支配**。精确解同时降低 M 与 cost（cost −0.451632 / −0.314089），说明作者解在这两图上既不是 M 最优也不是 cost 最优。
6. **LPT ≡ exact（逐位）**：6/6 图的 LPT 的 M 与精确最优 `diff = 0.0`；joint_minmax 在 12 s 亦相同；joint 在 3x10/5x35 的 cost 还与 exact 完全相同（其 `merge` 邻域会降 operating）。**结论：这 6 张图上 M_return 维度已无任何残余 headroom**。

下界公式（对每个站都成立，故取 max）：对任意划分，`Σ_trips length ≥ TSP(all)`（把各趟首尾相接去掉重复站点即得一条 Hamilton 回路），
`operating_s ≥ TSP_lb/speed + Σ service`，`makespan_s ≥ operating_s / n_slots`；
`TSP_lb = max(MST(全部节点), 2·max_i dist(station, i))`（两条都是合法下界）。

**下界校准（重要）**：把同一公式用在 6 张已精确求解的图上，`LB/M*` 分别为 0.837、0.696、0.748、0.932、0.718、0.598（均值 0.755），即**下界平均偏松约 25%，最松 40%**。
因此上表的 bracket 只能读成"最多还能再降 (UB−LB)/UB"，**不能**读成"接近最优"。5 张图一律 **UNKNOWN**。

## 11. 判定四分（已证实 / 未证实 / 失败 / 下一项）

**已证实（可复核）**
- 6 图（3x10_o1、3x15_o1、3x20_o1、4x25_o1、4x30_o1、5x35_o1）的 M_return **精确最优**及完整站级 (M, op) Pareto 前沿。
- 这些最优解 **admissible**（epsilon=0、domain 不变、issues 为空），与 scorer 的 M_return/cost 一致到 0 / 1.1e-13。
- LPT 与 joint_minmax(12s) 的 M 与精确最优**逐位相同**；有正 headroom 的 4 张图上 100% 被 1 ms LPT 吃掉，另 2 张图 headroom 本身为 0。
- 3x20_o1、4x25_o1 在现合同内 headroom = 0（前者 cap 阻断、后者单 slot 结构下界）。
- 6 图等权 headroom：均值 13.73%、中位 16.91%、最大 25.83%、合计 99.78 min、4/6 图 ≥5%。

**未证实（不得当结论）**
- 5 张大图（6x50/7x65/8x80/9x95/10x110）的 M_return 最优值——只知 [LB, UB] 区间。
- 任何"我们的方法比 LPT 好"的声明——在这些图上没有可改进空间，在更大图上尚无证据。
- n ∈ [9,14] 站的穷举等价性（只对 n ≤ 8 做了独立穷举对照）。

**失败 / 无**
- 本轮无实现失败；无超时（12 图 8.3 s ≪ 600 s/图）；无"精确解差于启发式"的矛盾（自查未触发）。

**下一项有界工作（按性价比排序）**
1. 把精确上限从 14 推到 **15–16**（3^15≈1.4e7、3^16≈4.3e7 转移，估算单站 5–20 s）→ 7x65 的 st2(15) 可精确，但 st3(18) 仍需 3^18≈3.9e8（C 实现或强剪枝）。
2. 对 **7x65_o1 的 st3（kind 1, n=18）** 单独用剪枝/分支定界（单 slot ⇒ 只需最小总时长划分，可用角度扫描 + 下界剪枝或 1-tree 界）把该图从 UNKNOWN 推到 EXACT。
3. 把 `exact_minmax.py` 接入 G3 资格：每批新图先出 EXACT/LB，再允许任何"改善率"表述。
4. 若要继续在 M_return 上找空间：把 exact 跑到 6x50 及以上（需更强算法），否则应把研究目标转到成本-时间前沿或 W 合同。
