## 2. 结构定理 T1–T6（本文件唯一新增数学内容；一页可写完）

记站 `s` 的可用 slot 集合 `I_s`（SABS=`{1}`，DABS=`{0,1}`；`global_env.py:47`、`scorer.py:121–143`），slot `(s,i)` 的累计 duty 为 `d_{s,i}`，单趟时长 `duration(trip)=len([s]+trip+[s])/v+Σ service`（`scorer.py:162–166`）。

### T1（整趟重排的成本恒等性）【已证实-代码+代数】

```
duty(s,i)   = Σ_{trip∈(s,i)} duration(trip)            scorer.py:175
operating   = Σ_s Σ_{i∈I_s} duty(s,i)                   scorer.py:187
cost        = fixed(station_types) + time_cost·operating  scorer.py:205
M_return    = max_s max_{i∈I_s} duty(s,i)               scorer.py:190,210
```

把**完整趟**在 `I_s` 内重新指派，只是把 `{d_{s,i}}` 在 `I_s` 内**重新排列**，故 `Σ_{i} d_{s,i}` 逐站不变 ⟹ `operating` 不变 ⟹ `cost` **恒等不变**；而 `max_{i}` 可下降。
**推论（E1 的机制解释）**：12.8% 是"在零成本代价下重新排列一个 max"的收益，不需要任何学习、任何路线改动。它与 C04 的成本不变量是同一件事：C04 证明"整趟重分配既不改善成本也不改善（成本）目标"，在 `min M_return` 目标下，同一条不变量恰好意味着"成本不变而 makespan 可降"。【C04 引用：`CLOSED_DIRECTIONS.md:29`】

### T2（免费增益的硬上界 = 平衡下界）【已证实-代数】

令 `L_s = Σ_{i∈I_s} d_{s,i}`、`K_s = |I_s| ∈ {1,2}`、`B = max_s L_s/K_s`。对任意解 `M ≥ B`（max ≥ 平均的逐站形式）。整趟重排不改 `L_s`，故

```
M_LPT ≥ B_0 = max_s L_s^0 / K_s        （B_0 由 anchor 直接算出，O(n)）
g := 1 − M_LPT/M_0 ≤ 1 − B_0/M_0 =: g_B
```

**这是 12.8% 的硬上界，也是本文件给出的一把审计尺**：若任一图实测 `g > g_B + 1e-9`，则那次"LPT"必然还改动了趟集合、跨站搬运了趟、或读到了与 scorer 不一致的 anchor duty ⟹ 该图结果**不得**作为基线。第二推论：**SABS 站 K=1，无可平衡**；若某图的瓶颈站是 SABS，则该图必须 `g ≤ 0`（无免费收益）。实测若出现 `g<0`，说明该 baseline **没有对 `M_return` 取 anchor/LPT 的较优者**（`baseline.py:207–220` 只判 `admissible`，不比较 `M_return`），属实现缺陷而非科学结果；注册基线时必须加一行 `min(anchor, LPT)` 保护。

### T3（ε=0 把可行域压成"净工作不增"）【已证实-代码】

`validate_candidate` 的预算 `budget=(1+0)·anchor.cost`（`scorer.py:273–277`），固定费由 domain 冻结（`:269–272` ⟹ station_types 必须与锚点相同）。故

```
admissible  ⟺  全部物理可行 ∧ station_types 不变 ∧ target_station 不变
               ∧  Σ_{s,i} d_{s,i}  ≤  Σ_{s,i} d^0_{s,i} + 2e-7   （cost 容差 1e-7 ÷ 0.5）
```

**推论**：拆趟（多一个 depot 往返，至少 `+2·dist(s,·)/v` 分钟）只有在**别处省回等量时间**时才 admissible。这一条就解释了 E2：`joint_minmax` 不是"没找到拆趟"，而是**拆趟被 ε=0 的 cap 挡住**；它实际能拿到的只是"净时间不增的再划分 + 纯路线节省"。

### T4（S 合同的可计算下界）【已证实-代数】

把站 `s` 的 `K_s` 条闭合路径（每条 `s→…→s`）在站点处首尾拼接，得到一条经过该站全部目标的闭合游走；其**长度** ≥ 该站目标集的 TSP 最优长度（空路径只让界更松，不破坏不等式）。记 `T_s := TSP_len_s / v`（**换算为分钟**，与 duty 同量纲）。故

```
M_return ≥ LB := max_s ( T_s + Σ_{n∈s} service_n ) / K_s
（T_s 可用 1-tree / MST 下界替代，O(n²)；这是可审计的、非学习的下界）
```

### T5（把"12.8% 之后还剩什么"写成恒等式）【已证实-代数】

```
M_0 − LB  =  [M_0 − M_LPT]  +  [M_LPT − M_part*]  +  [M_part* − B_0]  +  [B_0 − LB]
             └ (i) 整趟重排 ┘  └ (ii-a) LPT 次优 ┘  └ (ii-b) 不可分性 ┘  └ (iii) 路线/划分 ┘
```

- **(i)** 整趟重排：**已实测 12.8% 均值**（E1），零成本、约 1 ms、零学习。
- **(ii-a)** LPT 相对"整趟不可分下的最优二机划分" `M_part*` 的次优：m=2 时 Graham 界 `LPT/OPT ≤ 7/6`；而 **2 机带资格约束的精确划分本身可在毫秒级精确解**（子集和 DP / 分支定界，`|J_s|≈10–30`）。⟹ 该项**可被一个 1 ms 非学习步骤精确吃掉**。
- **(ii-b)** 不可分性缺口 `M_part* − B_0`：只要趟不可拆，这个缺口就存在（例：三趟 `(51,50,50)`、两台机，`B_0=75.5` 但任何划分的 max=100）。**攻它必须拆趟 ⟹ 撞 T3 的 cap**。
- **(iii)** 净工作不增的再划分 + 纯路线节省：唯一"尚未被干净测量"的项，E2 的 4 个百分点是它的一部分。

### T6（信息论证：S 合同是确定性全观测 MDP，估计步骤的方差恒为 0）【已证实-代码】

`global_env.py` 中 `random|seed|uniform|normalvariate` **0 匹配**（本线程 grep 实测）；给定 `(instance, anchor)` 与动作序列，轨迹、`M_return`、`cost` 唯一确定 ⟹ 对每个 `(s,a)`，`P(s'|s,a)=δ_{f(s,a)}`。于是：

```
rollout 的 H 条样本均值（Zhao pp.14–15）        = 单条确定性续接 = 确定性前瞻
后决策线性 VFA 的 RLS 回归（Zhao 式(14)）        = 对确定性函数做监督拟合
任何"估计"步骤的方差                              = 0，信息增益 = 0
唯一剩余的变量                                    = 墙钟内的搜索质量（anytime heuristic）
```

这与 C26 在另一对象上得到的"静态恒零"是同一条推理【`CLOSED_DIRECTIONS.md:51`】，也解释了为什么 PRIOR_ART §C.4 的三条可能新步骤在 **S 合同**上全部落空：(a) 无预报发布事件（S 无外生流）；(b) 确定性域里"按 slot 的反事实"就是确定性函数差，没有新的梯度对象；(c) 代码里**不存在**站容量约束（`CODE_MAP.md` §D 行 466：Han 的 `Σ_z r[z,b] ≤ N[b]` 标为 ✗ 未实现），没有可耦合的对偶/割。

> **T1–T6 合起来就是一句话**：S 合同下，"免费收益"已经被一个 1 ms 重排拿走 12.8%；剩下的是确定性组合优化；任何学习步骤在这里既没有信息可学（T6），也没有未被标准 CO 覆盖的构造（T5 的四项全部是经典构件）。下面 §3–§4 用这 6 条逐条筛查候选。

2. **数学对象**：在 T3 的可行域上做最速下降；邻域 = `{2-opt, relocate, split_relocate, swap, merge}`；键 = `(M_return, cost, total_distance)` 字典序（`baseline.py:245–249`）。
3. **逐式差异**：**无**。不触及 Zhao 式(14)（无 VFA）、不触及 (2r)–(2t)（无容量），也不产生新估计。
4. **预测**：若该项真有 >2% 空间，则 6x50 的 4pp 应在 8x80/9x95/10x110 复现。实测是**超时无输出** ⟹ 该预测既未被证实也未被反驳（无输出不等于无增益；见 §5.3 的实现污染）。
5. **最强 non-RL**：同一 VND 的**高效实现**（增量评估、first-improvement、无 deepcopy、候选抽样）+ LPT + 精确二机划分。
6. **关闭条件**：修完实现后，逐图配对增量中位 < 1% ⟹ 关闭为"无独立价值"。

### M02 精确二机平衡 + 平衡下界审计（**唯一被准入的用途：基线/审计，不是机制**）

1. **输入/输出**：输入 `(instance, anchor)`；输出重排后的完整解 + `(L_s, K_s, B_0, g_B, g)` 五元组。
2. **数学对象**：`min_{π} max_{i∈I_s} d_{s,i}`，`π` 为 `J_s` 在 `I_s` 上的指派，资格约束 `energy(t) ≤ battery_i+1e-7`；`|J_s| ≤ ~30`，精确解用子集和 DP/分支定界；总耗时毫秒级。
3. **逐式差异**：无（教科书）。**但**它是 C01/C04 的 ✅ 栏明确允许的"强 non-RL 对照"，故可用不可称机制。
4. **预测（可审计，强）**：`∀ map: g ≤ g_B + 1e-9`；且 `g ≤ 0` 对"瓶颈站 = SABS"的图成立。
5. **最强 non-RL**：就是它自己。
6. **关闭条件**：一旦有人把它写成"新机制/RL 创新"，立即按 C04 的 ❌ 栏判 NO-GO。

### M03 学"何时拆趟"的粒度 VFA

1. **输入/输出**：输入公共状态（slot duty 向量、剩余目标、cap 余量）；输出 `Q̂(s,a)` 或拆/不拆二分类。
2. **数学对象**：`V̂(s)=θ^Tφ(s)` 或 MLP，标签 = 完整续接的 `M_return`。
3. **逐式差异**：与 Zhao 式(14) **同为后决策线性 VFA**，仅特征换成 duty 向量；T6 说标签是确定性函数 ⟹ 等价于监督回归。PRIOR_ART §C.2 C4 已判"无"。
4. **预测**：监督版（同特征/同标签/同墙钟、无 RL 更新）与 RL 版差值 CI 含 0。
5. **最强 non-RL**：监督 VFA + 前向贪心；LPT + 精确划分。
6. **关闭条件**：监督版已等值 ⟹ RL 增量未建立。

### M05 cap 的 Lagrangian 对偶 + 逐站 min-max

1. **输入/输出**：输入 `(instance, anchor, λ)`；输出逐站子问题解 + 对偶值。
2. **数学对象**：`min_x max_s max_i d_{s,i}(x) + λ(Σd(x) − Σd^0)`，`λ≥0`；外层次梯度。
3. **逐式差异**：C19 已判"标准 primal-dual constrained RL，无 source-distinct 增量"；且 ε=0 时 cap 在 anchor 处**紧**（`Σd^0` 就是预算），对偶在可行侧退化。
4. **预测**：λ 的取值不改变最优解集（只改变搜索路径），或对偶界劣于 T4 的 `LB`。
5. **最强 non-RL**：同一 Lagrangian 的非学习求解。
6. **关闭条件**：对偶不产生更紧界或更好解 ⟹ 关闭。

## 5. 诚实回答：LPT 已经吃掉 12.8%，学习还剩下什么？

### 5.1 先说结论（三句）

1. **信息上剩 0**：T6——S 合同是确定性全观测 MDP，任何"估计/信用"步骤的方差恒为 0，学不到环境里不存在的东西。
2. **搜索上还剩一块，但它是确定性 CO**：T5 的 (ii-a)+(ii-b)+(iii)，其中 (ii-a) 可被 1 ms 精确划分吃掉，(ii-b) 只能靠拆趟而拆趟被 ε=0 的 cap 挡住，(iii) 是净零 VND。
3. **"5% 平均 + CI 下界>0"这个目标已经不是科学目标**：它已被一个零学习、1 ms、零成本的重排达成（E1）。任何 RL 主张必须打赢 **LPT+精确划分+高效 VND**，而不是打赢作者锚点。这是本轮最重要的口径修订。

### 5.2 数值账（全部为可复算的算术，不是新实验）

| 项 | 表达式 | 现在知道什么 | 谁吃掉它 | 学习能否介入 |
|---|---|---|---|---|
| (i) 整趟重排 | `M_0 − M_LPT` | **12.8% 均值 / 17.1% 中位 / 7-11 图 ≥5%**（E1）；上界 `g_B`（T2） | 1 ms LPT | ❌ 无信息可学 |
| (ii-a) LPT 次优 | `M_LPT − M_part*` | 未知；m=2 的 Graham 界 7/6；典型 ≪ | 毫秒级精确二机划分 | ❌ 精确解，无残余 |
| (ii-b) 不可分性 | `M_part* − B_0` | 未知；例 `(51,50,50)` 上 `B_0=75.5` 而最优 100 | 只能拆趟 ⟹ 撞 T3 cap | ❌ 撞 cap，非学习问题 |
| (iii) 净零再划分/路线 | `M_LPT − M_{VND}` | **只测到 6x50 的 ~4pp**；3 张大图**无输出**（E2） | 高效 VND（尚未实现） | ❌ 确定性搜索 |

**"还剩多少"目前不可报一个可信数字**，原因是 (iii) 的测量被实现开销污染，而不是被证明很小。这一点必须在任何"学习没空间"的表述里写明，否则就是过度声称。

### 5.3 为什么 (iii) 的现有测量不可信（新发现，重要）

`joint_minmax` 的实现在 `baseline.py:224–258`：每一轮**枚举全部邻域**（`_neighbours` 对 `combinations(locations,2)` 生成 swap、对 trips² 生成 merge、对每段生成 2-opt），**每个候选先 `deepcopy(base)` 再整图 `validate_candidate`**（`:239`，O(n) 评分）。于是单轮成本 ≈ `O(n²)` 候选 × `O(n)` 评分 × deepcopy。对 110 目标图，单轮即 `~10⁴` 次整图评分——**6 s 内跑不完一轮是实现的必然结果，不是方法的上限**。

⟹ **E2 的"超时"不能读作"路线改善空间小"**；它读作"该实现不是合格的最强 non-RL"。这同时说明 **G3 至今未通过的原因之一**：最强 non-RL 资格从未被一个实现上合格的候选建立过（TAKEOVER_AUDIT §1-5、§4.4 的 8 次导入失败／5 次超时也是同一类问题）。

### 5.4 那么"学习还剩什么"的最终表述

- **可学的对象**：无（T6）。
- **可优化的对象**：(iii) 的确定性搜索质量。它天然属于"anytime 启发式"，学习只能以**学得的 anytime 启发式**（neural CO）形式介入，而那是**应用**主张，不是机制主张：它必须（a）在 6s/12s 下打赢一个**实现合格**的非学习 VND，（b）另行通过六项中的第③项——而第③项目前是"无差异"，因为 min-max 多趟 VRP + 学习型构造/局部搜索已是成熟先例类（本项目已登记的 route-RL 先例审计即覆盖，C16）。
- **不可学的对象**：任何声称"估计/信用/信息"增量的东西（T6 直接判空）。
