## 附录：pomo_v2（2026-11-13 09:50 JST / Asia/Tokyo）— 在重训之前写入

本附录写于任何 `pomo_v2` 训练或 sanity 开始之前。原预注册的 POMO（下称 **pomo_v1**）三种子协议保持不变，其种子 0 结果已出并**冻结为失败**（`wx_e/GB_s0.json`，不删除）。本附录登记一个**新的标记变体** `pomo_v2`，用于在修复原则性缺陷后重训。选择仍只在 **dev** 上进行；test 仍只在 G-a（已 GO）且 G-b/G-c 通过后解冻。

### pomo_v1 种子 0 失败（已冻结，不作废删除）

- 最佳检查点 `models/rl_s0_best.npz` 与 `rl_s0_it0.npz`、`dagger_s0_r1.npz` **逐位相同**（权重 L2=0，Adam `t`=2807）。即 POMO 从未改进 DAgger r1。
- 正式 dev：J=5071.08（对 N1_240 **+0.40%**），准时率 +0.40 pp → **G-b 失败**；KL(RL‖BC)=0.83 但动作差异 0.65% → **G-c 失败**。
- 第一次评估之后即发散：it15 dev J=39085、准时率 0.16、holds=850；it30–75 的 J≈43979–44177、准时率≈0.14、holds≈970。训练 batchJ 从 8044（it0）升至 20637（it10）、68143（it25）。
- DAgger r0 其实更好（dev J=5042.80），r1 更差；v1 无条件从 r1 开训。BC 为 5046.38。

### 根因（调参之前先诊断，见 `wx_e/POMO_DIVERGENCE.md`）

1. **优势符号错误（主因）**。`PolicyNet.backward` 的损失为 `mean(w * (-log π(a)))`，对 `w>0` 的动作做**强化**（有限差分相对误差 ~1e-7，玩具任务上高成本 HOLD 的概率上升）。v1 代码写 `adv = (J-μ)/σ`，并注释「高 J = 惩罚」，但与该损失的真实梯度相反：高成本轨迹被强化。J 与 HOLD 次数在部分实例上正相关，长 HOLD 轨迹还有更多决策步、在决策平均中权重更大，形成向极端策略（几乎只 HOLD，或几乎不 HOLD）的正反馈。官方 76 步跑到了「几乎只 HOLD」。
2. **同一批数据上两次无重要性采样的更新**（无 PPO clip），策略一步可以走得很远。
3. **Adam 只保存了 `t`（DAgger 结束时 t=2807），未保存一阶/二阶矩**。POMO 起步等效于步长约 `3.16*lr` 的 sign-SGD（相对从 `t=0` 启动的第一次 Adam）。
4. **`σ+1e-6`**：K 条轨迹几乎一致时优势会爆炸（本诊断批次未触发，σ 最小约 5.9，但仍是隐患）。
5. **熵系数 0.01→0.001** 不足以阻止坍缩。官方 live 策略在相同状态上熵从 0.36 降到 0.036，贪心 HOLD 比例 0.71→0.90。

仅翻符号、其余超参数不动（`lr=3e-4`、两步无 clip、继承 t=2807）的 12 步复现：**仍不稳定**（探测集贪心 HOLD 从 0.64 掉到 0.01）。因此 v2 不是只改符号，而是一套有原则的稳定化。

### pomo_v2 协议（冻结）

标记：`--variant pomo_v2 --tag _pomo_v2`。产出写入带该后缀的新文件，**不覆盖** `GB_s0.json`、`models/rl_s0_*.npz`、`results/train_s0.jsonl`。

- **初始化（仅 dev）**：在已有的 `{BC, DAgger r0, DAgger r1}` 中取 **dev J 最低**者（种子 0 为 DAgger r0，J=5042.80）。若某种子还没有这些检查点，按原协议先跑 BC（3 epoch）与 DAgger 2 轮（M=8，200 天），再按 dev J 选初始化。
- **优势（符号修正）**：leave-one-out POMO 基线，`A_k = (μ_{-k} - J_k) / max(σ, σ_min)`，`σ_min=1.0`，`σ` 为该实例 K 条 J 的标准差。低 J → 正优势。K=1 或全体 J 相同则 A=0。
- **轨迹等权**：每条 rollout 贡献 `A_k * mean_t(-log π)`，避免超长 HOLD 轨迹在决策平均中占权。
- **PPO clip**：`ε=0.2`，每批 2 个 epoch（同一批，用采集时的 `log π_old`），无额外未加 clip 的内层步。
- **KL**：对冻结的初始化策略加 `β=0.05 * mean KL(π || π_ref)`；若本批更新后 `KL(π_new || π_old) > 0.03` 或 `KL(π_new || π_ref) > 0.15`，**撤销本批更新**（记一次 reject）。
- **梯度裁剪**：全局 L2 范数裁到 1.0。
- **Adam**：POMO 开始时重置 `t=0`、清空矩，不继承 DAgger 的 `t`。
- **学习率**：`1e-4`（原 3e-4）。若 dev J 超过初始化的 1.05 倍，恢复最佳检查点，lr 乘 0.5（只允许一次）。
- **熵**：0.02，在 200 次迭代内线性降到 0.005（原 0.01→0.001）。
- **K=8，B=24**（2 worker，尊重约 3 GiB 可用内存），每种子 RL 预算 ≤2 h（与 G-b 一致）。采集温度为 1（不用升温，以免 off-policy）。
- **选择**：全程只看 **dev**。每 10 次迭代（sanity 为每 5 次）做完整 20×10 dev 评估；官方检查点为 dev J 最优（并列时取准时率高者）。不得看 test。
- **记录**：每步写 gnorm、优势 mean/std/min/max、hold 比例、KL_ref、KL_step、batchJ、熵、reject 次数。
- **闸门**：G-b / G-c 定义与正文相同（对最强 NoRL=N1_240：J ≤ −0.5% 或准时率 +1.5 pp；KL>0.01 且与 N3/最强规则动作差异 ≥5%）。三种子，通过标准仍是至少 2/3。
- **G-c 对照**：与 BC 及最强规则（N1_240）都计算动作差异；预注册原文是「与 N3/best rule」，以 N1_240 为准并同时报 vs BC。
- **若原则性修复后 G-b 仍失败**：如实记录，不改闸门、不编造；仍做有意义的 P3 分析与 WX-H，并给出诊断。

### 执行顺序（本附录冻结）

1. 种子 0 的短 sanity（约 20–25 min，完整 dev 评估）：确认不再发散（dev J 不到 ~40k、holds 不升至 ~900），并且相对 DAgger 初始化有改进（dev J 更低或准时率更高）。
2. 若 sanity 通过：三种子正式重训（种子 0 复用已有 DAgger 检查点；种子 1–2 若缺则先跑 BC+DAgger）。RAM 限制下串行、2 worker。
3. 若 G-b/G-c 通过：按原计划做 Test-A、P3（均匀故障重训）、P4、价值网络与 WX-H。
