> 状态：设计 + 本地试点完成，正式实验在服务器跑（`wx3_server_run/`）。合成天气（不使用任何真实气象数据）。

## 1. 本地试点给出的三条关键证据（决定了 v3 设计）

1. **「N4/O 的大余量」大部分来自天气全知**（dev，M=16）：
   - 平静日 6000（n=20 图）：公平 N4f J 1016 vs N1 1417（−28%），特权 N4p 943；但 A1（从不待命）927 更好——平静日余量主要来自「别等」。
   - 风暴日 6001（n=12 图）：公平 N4f J 5704 vs N1 5632（**+1.3%，p=0.62**），ontime_h 0.625 vs 0.745（更差）；特权 N4p 4310（−23%）。
   - ⇒ 「用大余量讲故事」在风暴日不成立；我们把它变成**方法学贡献**（识别并修正 rollout 信息泄漏，给出量化），而不是性能声明。O 与 N4p 只作「全知上界」参照。
2. **逐状态 rollout 标签（API/ExIt/AggreVaTe）在本问题上学不动**：60 个训练日、M=8 的公平标签（3836 个状态）训练的 QNet，dev J 5406（劣于 N1 5050）；梯度提升树在留出天上的遗憾 87 vs 常数「总是待命」76。原因：待命/放飞的优劣主要由未来天气决定，单状态标签噪声远大于可观测特征能解释的信号。
3. **轨迹级进化策略（ES）稳定地改进**：从 pomo_v2(s0) 出发，对偶扰动 + 共同随机数（同一批训练日），64 个训练分布验证日（非 dev）：
   - it0 J 9319 → it40 J 8863（−4.9% 相对初始化；N1 为 9694，即 −8.6%）；
   - 同时 cost 1068→1024，fails 12.5→11.45，ontime_h 0.694→0.739，cvar_h 50.5→46.9（均优于 N1）；
   - **makespan 变差**（N1 431 → 507）。⇒ v3 加 makespan 拉格朗日项 λ_m 作为候选，由 dev 预注册规则选择。

## 2. v3 论文定位（贡献点）

- **C1 问题与公平评测协议**：风暴天气下无人机巡检的「待命/放飞/服务」动态派遣；指出并修正 sample-based lookahead 中共享仿真状态造成的**未来信息泄漏**（量化：风暴日特权 rollout 看起来 −23%，公平 rollout 实际 +1%）。这类「审稿人最怕的基线不公平」我们主动排除，并公开 twin 模型。
- **C2 方法 ES-RL**：在 PPO/POMO 预训练策略上，用**轨迹级、共同随机数的约束进化策略**做继续训练（`run_es.py`），目标 = J + λ_h·高优迟到分钟 + λ_c·CVaR_h + λ_m·makespan；λ 由 dev 上预注册的可行性规则选（ontime_h ≥ N1、CVaR_h ≤ N1 的前提下 J 最小）。推理仍是同一 2×128 MLP：**<1 ms/决策**、确定性贪心、逐位可复现。
- **C3 证据**：Test-A（同分布）、Test-B（作者 TSALNS 计划，计划结构分布外）、Test-C（压力：λ=3.5、p_f=0.5）、P4a σ×1.5、P4b 临近预报偏差；时延帕累托（同截止时间的公平 rollout 10/100/1000 ms，及 RL+前瞻 RLR）；全知参照 O、N4p。

为什么选 ES 而不是 PPO 继续训练 / API：
- 回报在一天结束才知道、天气方差极大：同一批天比较 ± 扰动（CRN）把天气方差抵消掉，这是逐状态方法做不到的（试点证据 2、3）。
- 40 核无 GPU：ES 是 embarrassingly parallel（每日模拟约 0.2 s），正好吃满 CPU。
- 直接优化论文报告的指标组合（可加约束项），不需要价值函数，也不需要可微。
- 文献支撑：Salimans 2017（OpenAI-ES）、Mania 2018（NeurIPS，ARS）、Choromanski 2018（ICML），见 SURVEY §7。

## 3. 方法细节（已实现）

- 策略网络：沿用 pomo_v2 的 PolicyNet（全局特征 2×128 ReLU + 每动作特征线性融合，掩码 softmax，贪心执行）。参数约 2.2 万。
- ES：每轮采样 24 对对偶噪声 ε_i（σ=0.02），在同一批 24 个训练（计划, 天）上评估 θ±σε_i；每天先除以该天 |F| 均值归一化，再中心化秩；Adam（lr 0.003）。噪声由整数种子在 worker 里重建。
- 训练日：`TRAIN_WX_MIN + 5e6 + seed·1e5 + j`（种子相关的 2000 个（计划,天）池），验证池 64 个（`+6e6`，各种子共用），都与 dev（6000s）/测试（7000s/8000s/8100s）不相交。
- 检查点：每 10 轮在验证池上评估中心 θ，保留最优；`es_state_*.npz` 每轮原子写入，可断点续跑。
- λ 候选（预注册）：`0:0`、`1:10`、`1:10:1`（λ_h 每高优迟到分钟、λ_c 乘 CVaR_h、λ_m 乘 makespan）。
- 种子：3 个（s=0,1,2），ES 种子 s 由 pomo_v2 种子 s 初始化 ⇒ 「ES 相对其自身初始化」是干净的配对消融（POMO_s* 作为基线一起测）。
- 等算力：每个 (种子, λ) 固定 300 轮 × 24 对 × 24 天（= 34,560 次整日模拟）；设 150 分钟墙钟上限防超时，实际轮数写入日志并在论文中报告。
- 选择（预注册）：每个种子的 3 个 λ 候选在完整 dev（20 图 × 10 天）各评估一次；取「dev ontime_h ≥ N1 且 dev CVaR_h ≤ N1」中 dev J 最小者；若无可行者取 J 最小并标记。dev 仅用于此选择与 N6 冻结。

## 5. 统计（预注册，见 PREREG_v3）

- 单位：地图（每图对天取均值），配对双侧 Wilcoxon；族内 Holm；效应量 = 匹配秩二列相关 r_rb；地图 bootstrap 95% CI。
- 由于天气只依赖天号：每个检验另报**天聚类 Wilcoxon**（n=30）与**地图×天交叉 bootstrap CI**；「确认显著」= 地图级 Holm 显著 ∧ 天聚类 p<0.05 ∧ 交叉 CI 不含 0。
- 报告种子均值（RL3_mean）为主，同时报每个种子（逐种子 Holm）。

## 6. 我们的强项如何被用上

| 强项 | 用法 |
|---|---|
| 对 N1 显著领先 | 主族：RL3_mean 对 N1/A1/A2/N6_best 的 6 个主指标 |
| <1 ms 决策 | WX-H：ES-RL（<1 ms）对公平 rollout 10/100/1000 ms 的时延-质量帕累托 |
| 确定性可复现 | 贪心确定性策略 + 固定种子 + 单入口脚本 + 断点续跑；同一 (θ, 计划, 天) 结果逐位一致 |
| 「余量」 | 如实拆分：全知余量（N4p/O）vs 可实现余量（N4f）；作为方法学发现写进论文 |

## 7. 可实现但有力度的预期（依据试点；不是承诺）

- 对 N1：J 约 −6%~−9%、cost、fails、ontime_h、CVaR_h 改进（试点在验证池上全部同向）；makespan 不保证（λ_m 候选专门处理，若仍劣于 N1 则如实报告为权衡）。
- 对 POMO（消融）：J 约 −3%~−5%。
- 对 A1/A2/N6：预计 J 显著更好；A1/A2 的 makespan 天然更短（不等待），这是已知权衡。
- 风暴日 vs 平静日分层：探索性。

## 8. 剩余风险（如实）

1. 试点只有 1 个种子、45 轮、64 个验证日；正式 3 种子 × 300 轮可能出现种子间差异。
2. dev 只有 3 个风暴日（6001/6005/6007），选择对风暴日的代表性有限。
3. makespan 很可能仍劣于 N1（需要如实写成权衡）。
4. 天气按天号共享：天级聚类检验只有 n=30，功效有限；部分指标可能「地图级显著、天级不显著」，按预注册不能称「确认」。
5. twin 模型保留了日气候超参数（ou_tau 等），属于「已知气候、未知实况」的设定，需要在文中说明。
6. 公平 rollout 在风暴日不占优，可能被审稿人问「为什么不用更强的前瞻」——我们的回答是：可实现余量就这么大，且 ES-RL 在 <1 ms 下已超过它；RLR 作为探索性结果报告。
7. 仍是单一仿真器、合成天气，外部效度需在讨论中限定。
