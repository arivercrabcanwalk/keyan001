## 1. 已披露的前序结果（不隐藏）
- v2：RL(pomo_v2) 对 N1_240 J −3.39%（p_Holm=1.4e-8）；P1、P2、P3 失败；P4 严格判定失败（实质持平）；N4d 实现缺陷。
- v3 试点发现：旧 N4 rollout 使用真实未来天气（特权）；天气种子只依赖天号；逐状态 API/ExIt 试点失败（dev J 5406 > N1 5050）；ES 试点在验证池上改进。试点只用训练分布日与 dev 日，**未触碰任何测试日（7000s/8000s/8100s）**。

## 2. 方法（冻结）
- 主方法 RL3 = ES-RL：`run_es.py`，PolicyNet 由 pomo_v2 种子 s 初始化，σ=0.02，lr=0.003（Adam），每轮 24 对对偶扰动 × 24 个训练日（CRN），300 轮或 150 分钟墙钟上限（先到为准，实际轮数报告），每 10 轮在 64 个验证日上保留最优。
- λ 候选：(λ_h, λ_c, λ_m) ∈ {(0,0,0), (1,10,0), (1,10,1)}。目标 F = J + λ_h·late_min_h + λ_c·cvar_h + λ_m·mk。
- 种子：s ∈ {0,1,2}。
- 选择规则（每个种子）：每个 λ 的最优验证 ckpt 在完整 dev（dev_ours × 6000–6009）上各评估一次；取 dev ontime_h ≥ N1_240 且 dev cvar_h ≤ N1_240 中 dev J 最小者；无可行者取 J 最小并在结果中标记 `feasible=false`。
- N6_best：H∈{30,60,90} × θ∈{0.1,0.25,0.5,1.0}，按 dev 平均 J 冻结。

## 4. 假设与检验族
主族 F-A（Test-A）：比较 RL3_mean（3 种子逐实例均值）对 {N1_240, A1, A2, N6_best} × 指标 {J, fails, cost, mk, ontime_h, cvar_h}，共 24 个检验，Holm 校正。
- H1（主要）：RL3_mean 的 J 显著低于 N1_240。
- H2：fails、cost、ontime_h、cvar_h 相对 N1_240 显著更好。
- H3：mk 相对 N1_240 —— **不预期一定更好**；双侧检验如实报告。
- H4（消融，独立 Holm）：RL3_mean 对 POMO_mean（同种子初始化）在 6 个指标上的比较；预期 J 显著更好。
- H5（泛化，独立族）：Test-B、Test-C、P4a、P4b 上同样的 24 检验族，分别 Holm。
- 参照（不入族、不作「击败」声明）：O、N4p_M32（全知）；N4f_M32、N4fd_*、RLR_*（时延/前瞻比较，独立 Holm 报告）。

## 5. 判定标准
- 单位：地图（每图对天取均值），配对双侧 Wilcoxon，α=0.05（Holm 后）。
- 「确认显著」（论文中称“显著”的唯一标准）：地图级 Holm p<0.05 **且** 天聚类 Wilcoxon（单位=天，n=30）p<0.05 **且** 地图×天交叉 bootstrap 95% CI 不含 0，三者方向一致。
- 只满足地图级的结果称「地图级显著（天级未确认）」。
- 效应量：r_rb；相对差的 95% CI。逐种子结果全部报告。
- 非劣（ontime_h、cvar_h）：若不显著，用交叉 bootstrap CI 判断：ontime_h 下界 > −1%（相对），cvar_h 上界 < +5%（相对）即称非劣。
