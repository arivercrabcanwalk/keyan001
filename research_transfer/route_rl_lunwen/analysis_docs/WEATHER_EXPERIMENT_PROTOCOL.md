# 风场与禁飞区实验接入协议

## 决策域

固定站点、站型和目标所属站。RL 每一步只选一个可服务目标或 RETURN；连续 target/RETURN 序列构成访问顺序和多趟划分。站点选择、搜索算子、邻域、repair、算法类型和计算预算均不属于策略动作。

多站 V1 的日志含 `(station_idx, slot, target|RETURN)`。其中 `station_idx` 仅是 anchor 固定 target owner 及其独立物理 slot state 的键，绝不允许改变 deployment、station type 或 target-station assignment；它不是 station-selection 决策。

该目录保留单站、单执行槽的可核查最小环境，也增加了 `weather_full_map.py` 的固定外层多站/异构槽 V1。后者固定 anchor 的站点、站型和 target-station 归属，使用 LD/SD 并行槽和 `M_return` 势差奖励；它仍是合成工程前置验证，不能替代原项目已冻结的 G3/G4 质量比较。

## 时间、风与禁飞区

1. 坐标单位为米、环境内部时间为秒、路线报告为分钟。默认空速 `900 m/min`，即 `15 m/s`。
2. 对航迹单位向量 `u` 和风 `w`，轨迹速度采用 `w dot u + sqrt(v_air^2 - |w_cross|^2)`。若横风大于空速或该速度不为正，该直线航段不可行。
3. 风在明确的 knot 时间处改变；积分不会把一个 knot 两侧的风速平均化。
4. 禁飞区为调用方已缓冲的严格凸多边形。只要航段的正长度内部交集在 `[on_s,off_s)` 有正长度时间交叠，就拒绝该航段；切线与恰落在关闭边界的交叉按半开区间规则处理。
5. 当前模型没有 WAIT 动作、随机风场、爬升/下降、充电排队、飞控动力学、地形或通信遮挡。任何此类因素都必须另建状态、动作、验证器和基准，不能被解释为本实现已覆盖。

## 目标、可行性与评分

- 目标完成时刻是飞抵并完成该目标服务后的时刻；最终返航不被算作目标服务完成。
- 单站夹具中 `MTC = sum_i completion_i / N` 是预定的路线级次指标。V1 多站环境报告它为次级项，并以全图最终返航时间 `M_return = max(slot clock)` 作为 reward 对账的主终点。
- 每一候选目标的合法性同时检验原行程能量、服务能量、返站能量、累计 duty、coverage 和必要成本下界。终局需再检查完整成本上限，重放器必须独立验证每个航段。
- 成本上限必须来自同一天气场景、同一固定外层条件下预先确定的共同可行参考路线。烟雾案例的 `1.25` 只为允许探索，绝不能复用为原项目 `epsilon=0` 的科学门槛。

## 从工程包进入注册实验的固定步骤

1. 先冻结区域/机型输入或继续明确标为区域无关仿真；不能用烟雾夹具校准真实风速、阵风、禁飞缓冲或能耗。
2. 冻结情景身份：每张地图的风 knots、禁飞区顶点与活跃区间、参考成本解、实例 hash 和随机 seed。
3. 使用 `weather_full_map.py` 和 `weather_replay.py` 的双实现，保持固定外层、多槽 `M_return`、原硬约束和完整天气成本 cap；独立 replay 仍须与原 evaluator 的未改变约束同时对账。
4. 先用同一动作/信息的随机、最近邻、贪心、beam 和同目标强非 RL 路线法验证；所有路径生成、模型加载、推理、验证、回退与失败耗时进入相同预算。
5. 只有在比较族、训练配置、checkpoint 规则、三训练 seed、地图分割和统计规则冻结后，才可在新的未暴露地图运行 PPO/A2C 或其他直接路线策略。

烟雾运行不能跨过原项目 G3/G4/G5 的准入要求，也不能生成 RL 胜出、新颖性或实飞适用性主张。
