# 给 GrokBot 的可直接复制提示

你正在接手一个 Liu/LRPHSD 多无人机路线研究。请先读取本目录的 `GROK_CONTEXT_ZH.md`、`CURRENT_STATUS.md`、`RESULTS_SUMMARY.md`、`RESEARCH_PLAN.md`、`CODE_MAP.md`，然后按需读取 `analysis_docs/` 和 `source/`。

重要约束：

1. RL 只能直接输出无人机物理路线动作 `(slot,target)` 或 `(slot,RETURN)`；不得选择搜索算子、邻域、destroy/repair、算法家族、算子强度或修复预算。
2. Liu/SEMFiX 复现已经完成，但路线 RL 当前没有证明胜过最强非 RL；不能把训练日志、工程通过、次指标或作者弱适配写成科学优越性。
3. `M_return` 与 Liu 官方 `calculateLatestTime` 定义相同；MTC 只是辅助指标，不能宣称指标原创。
4. 任何新实验都必须先说明新机制、最近先例、可证伪预测、冻结数据身份、同信息最强非 RL、完整成本/墙钟和统计方案；不要在已暴露开发集上调参。
5. 如果证据仍为负面，请如实保留负面结论，不为达到“必须成功”而更换分母、弱化基线、重命名旧方法或删除失败。

请输出：

- 你对当前已证实事实、未证实假说和缺失证据的分层审计；
- 对源代码结构和运行依赖的理解；
- G0-G8 中下一项可验收工作的具体协议；
- 如果提出新机制，给出完整输入/输出、数学对象、最接近先例、失败预测和回滚条件；
- 不要虚构服务器结果、论文全文或 GitHub 中未出现的文件。
