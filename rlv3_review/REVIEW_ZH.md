# rlv3 审计及实验安排

**审计起点：`c193b0d`。决定：可做工程验收；有真实 G0/G3 票据、新人口和成本基准才开开发训练。这不是 Formal 实验包或阳性实验结果。** 此次没有训练策略、求解历史地图或启动服务器。用户提供的烟测天气 J 是 615.4 vs 612.7（RL 高 2.7，约 0.44%）；复检 443.4 vs 443.4 是按显示精度持平，既不证明相等也不证明 RL 优于搜索。

## 四项改变研究解释的问题
| 旧行为 | 修订及验证 |
|---|---|
| 时限后的屏蔽放宽、强降恢复、整段提前记完成，低完成率可被隐藏；无跳过动作就称100%完成 | 任务发布、航行、到场、服务、返站按物理时钟记录；失败不瞬移。显式登记累积工时和资源，按实际完成与实返报告。大站小机的原工时由原站型决定而非机槽。可跨站的仅是 B 的已发布复检。 |
| 9点碰撞采样会漏掉中间短暂穿越；无风70图断言检查费用而不是全部能量 | 限定模拟几何，逐段连续相交检测，飞行、驻留、返航都查。风三角用地速算时间，功率用相对空气速度，地面定点才取风速大小。两点对齐是标尺，并非机型实测校准。固定风原节点服务能量单独计；同风完整作者的费用审核见 A 专章。 |
| PG采样与反传温度不一致，用同组标准差和总决策数归一；未来重采继承隐藏状态 | 把实际采样温度写进同一概率分布，独立轨迹留一基线，按轨迹均值，统一冻结回报尺度。手写有限枚举原估计 0.2331，修后与解析 1.6317 一致。BC/教师提示/静态计划特征分别消融。动态天气及聚簇任务还无合格公共条件采样器，不启用原“只学更好的未来”改标签。见[学习审计](../rlv3_weather/LEARNING_AUDIT_ZH.md)。 |
| 分析丢 error、重复键覆盖，只取成功交集；重跑只看同名 .done，失败后仍可能打印 ALL DONE | 事先冻结地图原字节、作者路线、每图每天的实际输入、方法与权重、代码、预算；逐格核对、保留失败，错误/缺失/重复则报告阻断。评估含冷启动到子进程真实退出；旧结果、旧 checkpoint 和标记不自动复用。 |

## 两项独立科学问题
- **A 固定风先做**：[天气设计](../rlv3_weather/DESIGN_ZH.md)。固定同风作者站址/机组/站归属，动作只选物理路线。先看合法、全部常规服务和返站，再看每图 `C≤C_author+1e-7` 下的最后返站分钟。不能拿 A1 静态低预算方案重评分代替同风完整作者求解。动态天气改变了物理与信息，需要新的作者适配和参照。原生强 min-max ALNS 与独立共同 H 是正式比较前仍需接入的对手，REOPT 是可运行的局部基线，不是这二者的替代。
- **B 零风零雷暴**：[事件设计](../rlv3_emergency/DESIGN_ZH.md)。随机/聚簇 × 低/中/高；先冻结一个主格，其余为压力/迁移，不按结果挑。分母是已发布的全部高优请求，分子需按 20 分钟到场且最终完成。普通复检为60分钟。遗漏、未到、到场未服务和未实返均留账。本模型仅节点决策，不能把结果写成自由在途抢占。时限是研究设定，不是真实业务 SLA。
- 两篇都限定在**作者部署给定后的路线层**。作者原优化费用；A 的新终点 M_return、B 的新终点及时率是条件问题，不叙述成从零完整击败作者。训练 J 是代理，不等于这两个主指标。
- 基本主臂是 BC+REINFORCE，实验同时登记 A1、GREEDY、REOPT、验证选择的调参版、同规模同训练预算的标准 PG、初始策略、BC-only、无提示；A 加去物理特征。每个学习臂至少三次独立训练；不使用 per-map 最好方法、最好 seed 或事后选的 checkpoint。η 奖惩不是保优塑形，只能作为另立协议的单因素试验。
- 同一底图的固定三风不是独立地图。当前随机生成器以地图与 day 一起派生输入，日嵌套在图内；跨图共享真实天气日则必须变更登记并使用交叉重抽，不能复用当前嵌套设置。B 逐次重抽后重算比率，零分母 N/A。当前 CI 为探索性，条件于给定模型；没有预登记功效与边际、独立强对手及未曝光 Formal 人口，禁止宣称优效、等效或安全非劣。比较更多终点前另冻结一主终点、最小实际效应和多重比较方案。
- 数据限制：本包天气和急单均合成。正式“真实天气”需独立标定两机型，以及注明 issue/available/valid 的多风暴预报；仅见未来雷达真值不等于有可用预报。B 要主张真实运维收益须有同业务发布、覆盖和 SLA 记录；在没有这些证据时只解释所给合成分布。资料：[Zeng 等](https://arxiv.org/abs/1804.02238)、[Liu 等](https://doi.org/10.1016/j.ejor.2026.04.046)、[POMO](https://arxiv.org/abs/2010.16011)、[NOAA HRRR](https://rapidrefresh.noaa.gov/hrrr/)、[NOAA 雷达](https://www.ncei.noaa.gov/products/radar/next-generation-weather-radar)。

## 可以执行什么
**先执行工程验收，再预检真实输入。** 仓库根目录的 `bash rlv3_review/check_all.sh` 会依次运行两包与跨包测试。两包的票据分别在[天气](../rlv3_weather/ticket.example.json)与[紧急](../rlv3_emergency/ticket.example.json)包内。带齐实际文件后，先用 `MODE=preflight`，不启动训练；同一台 hn01 上用相同的 TICKET、W、OUT 再切 `MODE=pilot`。固定条件和急单分开登记 `primary_condition`；`primary_reference` 在独立验证上核准，示例为 TUNED_OVERALL。局部 REOPT 不是完整作者。资料出处、数据缺口、可否证条件见[来源复核](SOURCES_ZH.md)。
1. 切到本次提交，进入任一包，执行 `bash setup.sh`，再执行 `MODE=check bash run_all.sh`（亦兼容 `SMOKE=1`）。新“冒烟”是工程检查，不是4图训练。目录内的工程 smoke 会用手写地图调用真实 evaluator→analyzer，输出 JSONL、`REPORT.md`、`table.tex`、CSV 及 `SMOKE.json`。本地实测见[验收记录](ACCEPTANCE.md)。
2. hn01 上在首个方法运行前冻结[开发票据格式](ticket.example.json)。示例仅是格式：并无获批 G0/G3、真实对照原件、新图和对应预算，不要用占位值冒充资格。用 hn01 的 `sha256sum /etc/machine-id` 摘要绑定实际主机，原 ID 不提交 GitHub。在同一 GPU 上按包**串行**运行：
   ```bash
   MODE=pilot W=4 TICKET=/absolute/approved-ticket.json OUT=/absolute/new-run bash run_all.sh
   ```
   一般建议先跑 A 三个已知恒风，再另立动态条件，B 使用单独票据。运行所需工具/依赖实际版本保存在环境与冻结清单；同 3090/5090 上的耗时未实测。不要把 13/16 小时当资源保证。
3. 票据需两个独立的门禁收据，每份是 JSON：`gate` 为 G0 或 G3；`status=APPROVED_FOR_DEVELOPMENT`，并有相同 `ticket_id, package, conditions, approved_machine_sha256` 以及 `reviewer, decision_basis`。只是身份核查，不是数字签名或自动批准。人口登记 JSON 含 `reviewed_prior_exposure:true`、`excluded_raw, excluded_geometry` 和 `expected_raw`（train_plans/val_plans/pilot_plans 各自精确 SHA 列表）。另排除旧 DEV、F3 的24图及派生；仅改路径、种子或平移不能当新图。
4. 三个数据阶段给 JSONL 作者方案。固定风训练与验证均用 `train_scenario` 的同风原件，并在 `selection_anchor_manifests` 指定各自 JSON（地图路径 → 原件路径）；三组地图互斥。pilot 的各风条件用同一批底图、分别用各自同风原件；B 不同负载/到达型、A 动态各条件的部署与路线必须完全相同。另按每种条件提供成本清单 `{"地图路径":{"日号":值}}`；固定风只用 `"0"`，值是该风完整作者原件的绝对路径；动态 A 和 B 是预登记的有限正数费用。[同风审核格式](../rlv3_weather/PHYSICS_AUDIT_ZH.md)。禁止重评分静风解、删去失败地图或补抽。
5. 每步保留命令、耗时、退出及输出 SHA；成功阶段可按同一收据复用。崩溃/超时的尝试不可静默重复覆盖。查看 `OUT/stages.json` 和阶段日志；须恢复时保留原账，在新票据明确恢复条件。超成本或缺失即使引擎退出0也不形成比较结论；报告可如实出现 BLOCKED。`MODE=formal` 预期 exit 2，本版本不签发论文结论。
